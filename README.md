# Agent-to-Entrepreneurship

> 面向大学生的跨平台个人学习、时间、知识与协作管理软件。

**项目名是暂定名称，不代表项目必然商业化或创业。** 当前阶段以解决真实学生需求和验证产品可用性为目标。

## 项目定位

把课程和个人事务、学习资料、AI 规划、专注执行以及小组协作连接成一条完整的工作流：**收集 → 组织 → 规划 → 执行 → 反馈 → 调整**。

- **目标用户**：高校学生；首批试点为上海交通大学。
- **首发平台**：Windows 桌面优先，macOS 从第一天参与适配、构建和测试；长期可扩展到 Web/移动端。
- **设计理念**：本地优先、跨平台、开放数据格式、可解释的 AI 建议、用户掌握最终控制权。
- **项目阶段**：W1 PRD V1.0 已审阅归档；W2 UI/UX 与 HTML 原型已归档，最终体验签收仍待完成；W3 技术架构已归档；W4 开发计划已确认并进入独立 PR 审阅。当前目标为 2026-11-25 交付 Windows/macOS 内部 Alpha；W5 代码开发尚未启动或获批。

| 模块 | 主要能力 | 规划阶段 |
| --- | --- | --- |
| 日历与任务 | 课表、作业、个人事件、截止时间、执行时间、提醒、冲突检测 | 首版 P0 |
| 个人知识库 | 多格式资料与转写、知识图谱、跨文档关联、AI 问答、智能综合复习、Obsidian 兼容 | 首版 P0 |
| 专注与自律 | 任务计时、安全的可配置程序限制、积分与自定义奖励 | 首版 P0 |
| 小组协作 | 聊天、任务认领/指派/验收、文件共享、角色权限、个人知识选择性分享 | 首版 P0 |
| AI 辅助规划 | 日/周/长期规划、动态调整、项目级文件夹授权、本地/云端模型选择 | 首版 P0 |
| 数据接入与扩展 | 真实 Canvas/交大教务/邮箱、Google/Outlook 日历、Notion、开放格式 | 首版 P0 |
| 邮件管理与 AI 通信 | 真实收发、分类、事项提取、主动回复建议、拟写及逐次确认发送 | 首版 P0 |
| 个人工作台 | 可自定义组件、主题背景、全局搜索、通知与快捷面板 | 首版 P0 |

首版**全部八大模块均须具备可验收的 P0 使用闭环**；复杂双向同步、模拟考试、自主 Agent 和桌宠等列为 P1/P2。详见已审阅的 [产品需求 PRD V1.0](docs/PRD.md)。

## 重点设计原则

1. **截止时间 ≠ 执行时间**：软件应帮助用户提前分阶段完成任务。
2. **基础功能不依赖 AI**：日历、任务、提醒和本地知识库离线仍可使用；邮箱基础阅读与草稿编辑不应强依赖 AI。
3. **用户掌控权限**：学校账号使用正式授权流程，私人日程不默认分享给团队。
4. **专注模式必须可安全退出**：严禁以损坏系统可用性或阻止紧急操作的方式达成“锁闭”。
5. **Windows/macOS 功能一致性**：共享核心逻辑，系统能力通过独立适配层实现；不能直接照搬锁闭功能。
6. **本地优先与选择性同步**：云同步由用户开启，大型 PDF/录音等原件按文件决定是否上传；本地读取和云 AI 外传权限独立设置。
7. **AI 项目级授权**：用户像管理项目工作目录一样指定文件夹、知识库或服务范围；默认为只读，操作权限单独控制。
