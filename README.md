# Agent-to-Entrepreneurship

> 面向大学生的跨平台个人学习、时间、知识与协作管理软件。

**项目名是暂定名称，不代表项目必然商业化或创业。** 当前阶段以解决真实学生需求和验证产品可用性为目标。

## 项目定位

把课程和个人事务、学习资料、AI 规划、专注执行以及小组协作连接成一条完整的工作流：**收集 → 组织 → 规划 → 执行 → 反馈 → 调整**。

- **目标用户**：高校学生；首批试点为上海交通大学。
- **首发平台**：Windows 桌面优先，macOS 从第一天参与适配、构建和测试；长期可扩展到 Web/移动端。
- **设计理念**：本地优先、跨平台、开放数据格式、可解释的 AI 建议、用户掌握最终控制权。
- **项目阶段**：产品规划／需求定义；尚无可用软件发布版。

## 八大功能模块

| 模块 | 主要能力 | 规划阶段 |
| --- | --- | --- |
| 日历与任务 | 课表、作业、个人事件、截止时间、执行时间、提醒、冲突检测 | MVP |
| 个人知识库 | PDF/文档/课件/录音转写、检索、笔记、Obsidian 兼容 | MVP 基础、后续增强 |
| 专注与自律 | 专注计时、允许列表、应用/网站限制、积分与反馈 | MVP 基础、后续增强 |
| 小组协作 | 共享任务、认领、进度、文件、会议、沟通、角色权限 | 第二阶段 |
| AI 辅助规划 | 工作量估算、空闲时段安排、动态重排、复习规划 | MVP 规则版、后续 AI |
| 数据接入与扩展 | Canvas、交大开放 API、ICS、通用连接器、自动化、插件 | MVP 基础、后续扩展 |
| 邮件管理与 AI 通信 | 邮箱同步、智能分类、事项提取、邮件拟写、监督发送与回复 | MVP 基础、P1 完善 |
| 个人工作台 | 今日总览、统一事项收件箱、邮件摘要入口、每日简报、每周复盘 | MVP |

详细内容见 [产品需求](docs/PRD.md)。

## 重点设计原则

1. **截止时间 ≠ 执行时间**：软件应帮助用户提前分阶段完成任务。
2. **基础功能不依赖 AI**：日历、任务、提醒和本地知识库离线仍可使用；邮箱基础阅读与草稿编辑不应强依赖 AI。
3. **用户掌控权限**：学校账号使用正式授权流程，私人日程不默认分享给团队。
4. **专注模式必须可安全退出**：严禁以损坏系统可用性或阻止紧急操作的方式达成“锁闭”。
5. **Windows/macOS 功能一致性**：共享核心逻辑，系统能力通过独立适配层实现；不能直接照搬锁闭功能。
