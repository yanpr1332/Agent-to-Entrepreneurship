## 设计基础（已确认）

- 八大模块均为首版 P0 且分别具有可真实验收的闭环；**分批研发不等于分批缩减 P0 发布范围**。
- 采用**混合工作空间方案 C**：左侧导航＋个人/团队/AI 项目切换器；顶部搜索、创建、通知；中间主操作区；可折叠的右侧上下文详情。
- 邮件为独立一级业务模块，不能被挤入工作台；工作台只呈现邮件摘要、待确认建议及跳转。
- 知识图谱、跨文档关联、自动复习、可信出处 AI 问答均是 P0；模拟考试、薄弱点专项训练是 P1。
- Canvas/教务/交大邮箱及明确列入 P0 的外部接入需要真实合规授权与实测；原型中的“已连接”模拟态不得视为验收。
- 具备单人审核的团队任务是 P0；**根据任务重要性设置多名审核人及通过票数**是 P1，P0 需保留扩展位置。
- 程序限制须可安全退出及恢复；所有邮件发送须用户在完整预览后逐次确认；AI 本地读取授权不等于允许云端外传。
- PDF、录音等大原件**逐文件决定云同步范围**；本地数据与团队共享数据相互隔离。
- 工作台 P0 支持组件显隐、调整顺序、基础尺寸、布局预设、主题、背景；复杂智能布局与桌宠为 P1。
