# W2-1 · 信息架构、导航、页面清单与交互框架

> 已选方案：C「混合工作空间」。本文件确定**用户如何找到并操作功能**，不以视觉配色草案替代业务流程。组件造型、动效与高精度视觉优化可后续迭代，不改变既定导航骨架。

## 1. 四区域布局及各自职责

| 区域 | 默认呈现 | 交互约束 | 失效/折叠行为 |
| --- | --- | --- | --- |
| 左侧固定导航 | 品牌、空间切换器、八大一级模块、设置入口、用户身份 | 模块始终可识别；模块标签与图标一致；当前选择高亮 | 窗口过窄可压缩为图标栏；必须仍可找到完整导航 |
| 顶部工具栏 | 面包屑、项目名、全局搜索、快捷创建、通知、右栏开关 | 搜索只查询当前授权；创建默认带入所在空间，允许改范围 | 离线或缺权限时显示范围标签，不展示虚假成功 |
| 中央内容区 | 当前模块首页、筛选、列表、看板、时间线或编辑器 | 提供主操作与明确的确认/撤销；长任务可离开页面后台处理 | 空白/加载/错误/离线状态有独立说明和恢复路径 |
| 右侧上下文栏 | 被选任务、邮件、文档、知识节点的详情、证据、历史、下一步 | 不替代完整编辑页；上下文随当前选择变化；可收起 | 无选中时显示引导而不是旧对象；折叠不丢失尚未提交编辑 |

桌面宽度优先覆盖 1280×800 左右的常见窗口，同时支持较小窗口的折叠布局和系统文字放大；具体断点、最小宽度在 W3/视觉验收中按真实设备确定。不要把左栏固定宽度作为权限或业务逻辑的一部分。

### 工作空间切换

`个人空间 → 课程/团队项目 → AI 项目空间` 从同一切换器进入，三种空间并非同一数据权限：

- **个人空间**：默认私有；今日总览、私有任务/知识、个人邮箱、个人日历等。团队任务可以在个人待办以**引用**出现，但授权、审核、版本归属仍属于团队。
- **课程/团队空间**：以项目概览为首页，包含讨论、任务、文件、成员与项目共享资料。切换空间只改变观察范围，绝不自动共享个人知识库或完整私人日历。
- **AI 项目空间**：围绕目标建立独立会话、被授权数据集合、工具权限和模型配置；像 Codex Project 一样可指定某些本机目录、文件、知识库集合、邮件文件夹与团队空间；每个项目的授权独立可撤销。
- 切换时同步变更面包屑、标题、创建操作默认归属和搜索范围；仍在编辑的草稿提示保存/保留/放弃。未连接网络时可进入本地内容，但需远端的团队数据不得伪装为最新。

## 2. 一级业务导航与页面树

以下八个业务模块均必须在导航或空间子导航中有稳定可达的独立入口，不能仅留在设置或搜索中。

| 模块 | 首页 | 必须可达的子页面/视图 | 从何处跨模块进入 |
| --- | --- | --- | --- |
| 1 日历与任务 | 今日/本周时间线 | 日/周/月/学期日历、课程表、个人任务列表、任务详情/子任务、AI 时间块层、冲突处理、提醒 | Canvas 作业、邮件事项、团队任务引用、AI 排程 |
| 2 个人知识库 | 最近资料/待复习 | 文件集合、导入与 OCR/ASR 状态、原文/转写编辑、全文/语义搜索、引用式 AI 问答、知识图谱、关系核验、复习队列/作答、Vault 管理 | 项目授权、复习计划、团队分享、全局搜索 |
| 3 专注与自律 | 任务/专注入口 | 时长/模式设置、白名单/黑名单、限制预览、专注浮层、紧急退出、会话统计、积分及现实奖励兑换 | 日历任务、AI 今日计划、工作台快捷启动 |
| 4 小组协作 | **项目概览** | 任务看板/分配/认领/验收、讨论/聊天、团队文件、成员与角色、选择性共享知识、里程碑与项目日历 | 个人待办、消息转任务、分享选择器 |
| 5 AI 智能规划与项目空间 | 今日/本周建议 | 长期目标、阶段里程碑、计划草案与差异、排程批量确认、动态重排、AI 项目列表/详情、数据授权、模型配置与用量 | 任务、知识复习、邮箱候选、工作台待确认 |
| 6 数据接入与扩展 | 连接总览 | Canvas/教务/交大邮箱/Google Calendar/Outlook Calendar/Notion 连接详情、授权范围、同步中心、逐文件同步、导入导出映射、文件夹访问管理 | 首次启动、邮件账号、日历来源、知识导入 |
| 7 邮件管理与 AI 通信 | 独立智能收件箱 | 收件、会话详情、AI 分类/待确认建议、新邮件/回复/全部回复/转发编辑器、草稿箱、已发送、发信最终确认、账号/文件夹 AI 分析范围 | 工作台摘要、邮件事项与日历、项目范围配置 |
| 8 个人工作台 | 今日总览 | 待确认中心、通知中心、快速创建/全局搜索、自定义组件与主题背景、预设布局、托盘快捷面板 | 所有模块的摘要及深链接 |

**共用设置**（不算第九业务模块）：身份与可选 jAccount、隐私授权、模型与密钥、通知与免打扰、语言与键盘、备份/恢复、诊断、平台权限、云同步。某一配置项可从业务模块深链抵达，但应复用同一个设置状态。

## 3. 首次启动（Onboarding）

1. 欢迎与隐私概览：说明软件可本地离线使用、联网功能需要授权、部分能力有外部费用/权限要求。
2. 选择「本地开始」「独立账号注册」「已有账号登录」；交大 jAccount 绑定是**可选动作**，非交大学生不能被阻挡。
3. 首次连接向导展示 Canvas、教务、SJTU 邮箱以及后续 Google/Outlook 日历、Notion 的接入卡片；每张卡片分别授权，可跳过，失败时提供重试及手工导入后备路径。
4. 可选授权本机文件夹/Obsidian Vault、导入历史课件/笔记；**文件夹读取权不等于云同步或云 AI 外传许可**。
5. 可选挑选工作台预设、基础主题并进入首页；未完成步骤在设置中可继续。
6. 关闭、拒绝权限、断网、登录超时等中断后仍可启动本地功能；再次启动应能恢复向导位置或明确重新开始。

## 4. 共用导航与交互细节

- **位置可见**：全局面包屑标明 `工作空间 / 模块 / 子页面 / 对象`，在详情面板显示来源和上次更新。
- **深链接**：邮件候选点击“查看原件”回到相应会话；知识节点能回到 PDF 页码或 ASR 时间点；团队任务能回到对应项目；外部课表能打开来源链接。
- **全局搜索**：可按个人/课程/团队/AI 项目及任务/资料/邮件/事件过滤，结果标出来源；不能检索未经授权数据。输入错误、无结果、索引中、离线、权限不足须区分。
- **快速创建**：顶栏“＋”可创建任务、事件、笔记、团队任务、邮件草稿；先选择目标空间或根据当前位置预填，保存前显示归属。误创建支持撤销/恢复。
- **通知中心**：逾期/到期、团队审核、待回复邮件、同步冲突、外部授权失败、复习待办；通知显示来源及时间，可跳转、标已读、配置静默时段。
- **右侧栏**：任务详情可显示截止时间与建议执行时间两项；知识关系展示证据与已确认状态；邮件显示发送身份及当前线程；无选中时不继承上一对象敏感内容。
- **多标签/历史**：至少保留明确返回上一页的路径；离开有未保存草稿时提示保存/舍弃，避免路由切换导致丢稿。
- **托盘/菜单栏**：Windows 通知区域、macOS 菜单栏提供下一事项、快捷创建、开始专注、打开主窗口；无法注册快捷键或系统权限关闭时主窗口仍可完成全部操作。

## 5. 交互状态分工

页面组件不直接伪造“已完成”：真实对象状态由相应业务模块维护，工作台展示引用。特别注意：

- `截止日期` 与 `建议执行时间块` 是不同数据。拖动执行时间块不应写回 Canvas 作业截止日期。
- `AI 候选` 与 `已确认任务` 是不同实体。推荐项应有接受/修改/忽略/查看来源，重复候选可去重。
- `外部账号已授权` 不意味着 `已同步完成`，更不意味着 `正式发布无需审批`。
- `团队任务完成` 与 `负责人验收通过` 是不同状态；未通过前不允许以成功状态欺骗全组。
- `邮件已准备草稿` 与 `发送确认`、`远端已发送` 分离；状态未知时停在核验中。
- `本地文件可读`、`已同步元数据`、`原件已上传`、`允许云模型外传` 相互独立。
