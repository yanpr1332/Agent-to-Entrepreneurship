# W2-3 · 八大模块的关键用户旅程与跨模块闭环

> 每个流程包含前置条件、操作步骤、界面反馈、输入输出、异常分支与 P0 验收。原型中的按钮仅模拟用户交互；开发时必须由真实业务状态及权限执行层接管。

## F01 首次启动、账户与空间初始化（系统入口，所有模块共用）

**用户故事**：一名新用户刚安装软件，可能有交大身份，也可能不是交大学生；希望立即使用本地功能，之后再决定是否注册或连接学校服务。

- **前置/输入**：无历史配置，或已有独立账号、jAccount、旧本地资料。可选输入注册邮箱、登录凭据、校园绑定授权、本机资料目录与工作台主题。
- **界面步骤**：①欢迎页说明本地/联网区别和隐私原则 → ②选择本地开始或独立账号登录/注册 → ③可选校园账号绑定 → ④选择连接 Canvas、教务、邮箱和第三方服务，分别申请必要权限 → ⑤可选导入本地文件/Obsidian Vault，指出项目权限与文件云同步须独立设置 → ⑥选工作台预设并进入主界面。
- **输出**：已初始化的**个人私有空间**、必要的本地数据目录/账户凭据配置、未接入服务的真实状态、可随时重开的引导流程。
- **状态/提示**：每步提供“跳过/返回/重试”；授权失败时保留已成功部分；断网时不阻止进入本地日历、任务与资料页；登录、校园身份与团队身份分别显示，不因 jAccount 绑定自动提高团队权限。
- **P0 验收**：新用户无交大账号可以用本地任务与知识库；重启保留初始化状态；拒绝一个服务授权不影响其他服务；界面不要求用户安装 WSL、Obsidian 或特定云模型。

## F02 校园和第三方连接的授权、同步、解除（数据接入与扩展）

**用户故事**：交大学生要把 Canvas 课程作业、教务课表和邮箱通知汇总至软件，同时同步 Google/Outlook 日历或 Notion 资料，但希望知道各服务到底授权了什么。

- **前置/输入**：用户已登录或选择本地空间；可合法获得目标服务的授权，选择账户、范围、日期和同步频率。
- **界面步骤**：①打开「数据接入与扩展 / 连接管理」 → ②看到六类连接器各自当前状态 → ③选具体服务并查看授权目的、读取字段、是否支持写入、令牌存储说明 → ④启动服务允许的授权方式 → ⑤验证实际账户与资源 → ⑥显示同步进度、来源、数量、更新时间和错误列表 → ⑦可手动同步、重连、缩小范围或断开。
- **输出**：带来源 ID 和最近同步时间的 `Course / Event / Task / Mail / Note` 等对应领域对象；数据接入模块只负责认证、拉取与映射，正式任务和邮件草稿由各自模块维护。
- **规则**：Canvas/教务/Google/Outlook Calendar/Notion 的 P0 预设单向**读取**同步；账号在学校已有“已提交”不等于用户的个人任务完成。Google/Outlook **邮箱专用**接入属于 P1，不能与日历授权混淆。
- **失败路径**：授权被取消、管理员禁止、令牌失效、分页缺漏、限流、断网、课表变更。显示“待授权/授权中/已连接/同步中/需重连/权限不足/同步失败/已断开”；提供重试或 ICS/CSV/Markdown 导入，但手工导入不能冒充真实 P0 官方 API 接入。
- **P0 验收**：在允许的真实账号上测试读取与同步；来源和个人备注不丢失；重复同步不产生重复任务；服务被撤权后新远端读取失败且本地缓存处理可由用户决定。

## F03 导入资料 → 可追溯问答 → 图谱 → 自动复习（个人知识库）

**用户故事**：学生导入论文 PDF、课件、课堂录音与 Obsidian 笔记，希望不再手工把资料整理成多个无法联系的文档，并能自动得到复习计划。

- **前置/输入**：获得本机文件/目录授权；选 PDF/Word/PPT/TXT/Markdown/网页/图片/音视频或 Obsidian Vault；选择课程/项目标签、文件云同步范围和 AI 本地/云端处理许可。
- **步骤一：导入**。①选择单个/多个文件或 Vault 目录 → ②预览文件名、格式、大小、来源及同步选择（大原件默认“仅本机”） → ③建立索引并分步显示解析、OCR、ASR、校对进度 → ④查看可编辑转写、OCR 错误提示与 PDF 页码/音频时间戳 → ⑤选择是否让已授权模型处理资料。
- **步骤二：学习**。①资料列表/全文搜索 → ②在有权限的文档集合里提问 → ③回答展示真实文档引用与可定位片段；无证据时明确回答“不确定” → ④选择“查看图谱”展示概念节点、不同来源的关联，AI 新边标待核验 → ⑤人工合并/修正/接受后成为正式边。
- **步骤三：复习**。①从已确认来源生成闪卡/选择题/简答题 → ②进入今日复习队列并作答 → ③查看原文参考及系统建议掌握度 → ④用户可修改评价 → ⑤确认保存后生成下次复习日期 → ⑥向 AI 规划/日历发送待确认的复习时间建议。
- **输出**：本地资源索引、可追溯知识节点/边、问答历史、复习卡及评价、复习排期候选；原文件不得在解析失败时丢失或被覆盖。
- **失败路径**：扫描件 OCR 低可信、录音不可识别、索引后台失败、外部 Vault 文件变化、PDF 已移动、云模型无许可、数据源撤权、知识边来源冲突。每种情况保留原件并提供重新绑定/校对/重试；不虚构引用。
- **P0 验收**：两份真实文档的一条跨文档边可点击到两个出处；ASR 文字跳转到录音时间点；待核验边与正式边区分；用户自评更改下次间隔；不安装 Obsidian 也能读取 Markdown；模拟考试和弱点专项仍是 P1。

## F04 长期目标 → 选择性 AI 排程 → 任务执行 → 专注/奖励（日历、AI、专注）

**用户故事**：学生想在三周内复习完分子生物学，希望系统综合课程表、任务与复习内容安排每天做什么，但保留人工决策权。

- **前置/输入**：目标、截止日、章节/里程碑、估计耗时、工作/休息偏好、已有固定课程及锁定事项、到期复习卡、选定模型与项目作用域。
- **规划步骤**：①新建长期目标 → ②系统提出阶段里程碑、可编辑任务 → ③在日/周日历上以单独样式预览候选时间块 → ④用户拖动/修改估时、过滤冲突与不现实安排 → ⑤选择任意子集，查看影响 → ⑥确认后应用；未选块仍是建议，截止日期不被覆盖。
- **执行步骤**：①打开某个任务 → ②选择轻量/严格专注 → ③严格模式展示实际权限、黑白名单、剩余时长和紧急退出 → ④用户确认才开始 → ⑤过程中可查看状态、暂停/临时放行、必要时紧急退出 → ⑥计时结束后由用户确认任务实际完成度 → ⑦如是团队成果，继续等待负责人审核 → ⑧根据真实结果更新统计、积分和自定义现实奖励兑换记录。
- **变化与撤销**：临时加课或日程变化时系统提出“重排差异”，默认不改变用户锁定事项；可逐条撤销刚确认的执行块。离线时支持手动创建任务与日程。
- **失败路径**：模型不可用、时间不够、候选与学校日程冲突、严格权限被拒绝、应用崩溃。前者回退到手工安排；严格限制出问题时以解除 OS 限制、恢复系统访问为优先。积分不得因任务重复提交而重复增加。
- **P0 验收**：三周目标能产生阶段任务和可操作的候选；部分应用不影响其他建议；已锁定课程不被移动；会话结束不自动宣称任务完成；两平台严格专注均通过安全退出与异常恢复测试。

## F05 AI 项目新建、局部文件夹授权与撤权（AI 智能规划/项目空间）

**用户故事**：用户建立“iGEM 工作”与“期末复习”两个 AI 项目，允许各自访问不同目录与知识库，就像为 Codex Project 设定工作区，但不允许 AI 扫描全盘或自动上传课件。

- **前置/输入**：项目名称、用途、允许访问的文件/文件夹/子目录排除清单、知识库集合、邮箱文件夹、日历、团队空间、Git 仓库；操作权限（读、写、外部调用）、授权期限、模型/密钥选择。
- **界面步骤**：①创建 AI 项目 → ②选择本机目录或资料、排除敏感子目录 → ③选择特定知识/服务数据源，显示用户本身权限限制 → ④设置本地读取、写入原件、云模型发送片段、云模型发送原件等**分别授权** → ⑤查看作用域预览和风险提示 → ⑥确认创建/保存 → ⑦使用时显示本次访问的来源与模型处理位置 → ⑧可随时停用模型、撤销授权或要求每次敏感修改先审阅。
- **权限原则**：实际允许范围＝用户权限 ∩ 当前项目授权 ∩ 此操作的授权；不应靠“请 AI 不要访问其他文件”的提示词实现。相邻文件夹、符号链接、上级路径、历史缓存及跨项目引用必须经过真正的权限检查。团队角色变化后即时生效。
- **输出**：可查看的项目配置与授权审计记录；可受控的 AI 建议、草稿或修改请求；最终写入源文件应显式预览差异并获得权限。
- **异常路径**：路径不存在/移动、另一 OS 无对应目录、令牌撤销、Git 仓库只读、API Key 缺失、云费用不足、模型不可用。界面提示受影响范围和可恢复方式；不偷偷选择其他模型或把资料传至云端。
- **P0 验收**：仅授权 `课程资料/分子生物学` 时访问相邻文件夹被拒；云外传开关关闭时即使本地可读也不可发送；撤权后新操作被拒；跨 Windows/macOS 目录需要重新绑定。

## F06 邮件 → 待确认日历/任务 → 草稿 → 最终监督发信（独立邮件模块）

**用户故事**：学生经合法方式接入交大邮箱，AI 把教师通知中的作业截止时间提为候选，之后帮助用户写回复，但实际发信必须由本人控制。

- **前置/输入**：已获授权的邮箱、账号/文件夹分析范围、原始线程、提取目的、收件人/抄送/密送、附件、草稿正文。
- **收件转事项**：①打开智能收件箱 → ②查看邮件原文、来源与同步时间 → ③允许范围内 AI 分类、摘要并提取日程/作业/待办 → ④候选显示证据、日期和不确定信息 → ⑤用户编辑并在邮件页或工作台待确认区批准 → ⑥真正创建任务/事件并保留邮件来源、去重键。
- **拟写与发送**：①点击新建/回复/回复全部/转发 → ②用户输入目的、语气和要点 → ③AI 产生可编辑草稿（可不用 AI 手工写） → ④用户选择发件账号、To/Cc/Bcc、主题、正文、附件 → ⑤点击准备发送 → ⑥**独立最终弹窗**完整预览全部信息、线程及新增收件人 → ⑦用户逐次点击确认发送 → ⑧适配器仅执行一次真实发送并回填状态。
- **关键状态**：`草稿/待最终确认/发送中/已发送/失败/结果待核验`。离线时允许本地草稿，不能跳过最后确认；若发送超时先检查远端已发件箱/消息 ID，再由用户决定是否重发。
- **安全**：邮箱正文与附件属于不可信内容，不得通过提示注入提升授权或影响发送对象；附件不是 AI 自行从本机搜集；云模型必须另获邮件内容外传授权；Reply-All 新增外部地址显著提示。
- **P0 验收**：交大真实邮箱的合法收/写/发/回复；用户关掉某文件夹 AI 分析后该文件夹不进入模型；没点最后确认不会出现发件请求；发送状态未知不自动二次发信。

## F07 小组项目概览、聊天、任务与选择性知识共享（小组协作）

**用户故事**：iGEM 小组共同组织演讲稿、PPT 和讨论任务，同时每个人的私人课程与知识库默认不对全组开放。

- **前置/输入**：独立账号、团队邀请、团队角色、任务内容与截止日、负责人/认领方式、可选审核人、选择共享的文档/节点/集合与读写权限。
- **正常操作**：①创建/加入团队 → ②打开默认项目概览 → ③进入讨论发送消息/附件或由消息创建任务 → ④在任务看板分配/自由认领/拆分 → ⑤成果提交 → ⑥无审核任务直接完成；需审核任务进入待验收，由 P0 单负责人批准/退回 → ⑦个人工作台显示被分配任务的引用与审核结果 → ⑧选择私人知识的**指定**节点/文档/集合及角色授予共享权限。
- **输出**：唯一团队任务记录、协作消息、附件与版本、项目进度、审核历史、用户选择的共享对象映射。私人日历的“可用/忙碌”信息可以摘要显示，但不自动公开详情。
- **异常路径**：网络掉线、消息未送达、成果提交被拒、角色或项目成员发生变化、文件已经被他人下载。界面展示待同步或权限不足；撤权后阻断新的访问，同时说明已下载副本不能保证回收。
- **P0 验收**：从项目概览可达任务/讨论/文件/成员；只授权单篇文档时其他私人文档无法读；成员自完成不等于负责人通过；多人审核人数/通过票数属于 P1，P0 保留未来配置入口即可。

## F08 本地优先、逐文件同步、冲突与撤回（数据接入/设置）

**用户故事**：Windows 台式机有大量 PDF 和课堂录音，用户希望同步任务、部分课件到 Mac，但不想上传不必要的录音原件。

- **前置/输入**：用户可选登录并启用云同步、两台设备本地数据、文件元信息和同步选项。大型原件默认本地保留。
- **逐文件设置**：①打开同步中心 → ②查看文件/资料集合及状态 → ③每个 PDF/音频/视频可选择 `仅本机 / 同步元数据 / 上传原件`，批量操作可被逐文件覆盖 → ④显示预计传输量、范围和云端处理提示 → ⑤用户确认 → ⑥显示上传/下载进度、失败/重试、另一设备的占位与按需下载。
- **离线与冲突**：断网可本地编辑任务、笔记、复习记录；联网后根据变更版本检测冲突，展示「本机版本/远端版本/保留两份」及差异和备份路径，未经用户许可不覆盖原件。不同设备无法沿用同一个 Windows/macOS 本地路径，需单独重绑定。
- **撤回与删除**：「停用未来同步」不会自动从云端抹掉历史副本；「请求删除已上传云端副本」须另行显示删除范围与可能的后果，不夸大对他人下载副本的可撤回性。云同步许可不等于把文件交给云 AI 处理。
- **状态**：`仅本地/仅元数据/待上传/上传中/已上传/需下载/失败/冲突/待处理删除`；离线队列显示准确，不得把待同步误当已同步。
- **P0 验收**：同步 PDF A 而不选录音 B 后，Mac 能依据权限按需下载 A、B 原件从未上传；发生跨设备冲突时可保留两份并恢复；撤销未来同步不会错误清除唯一原件。

## F09 工作台、个性化、搜索及托盘快速操作（个人工作台）

**用户故事**：用户不想每天逐个打开八个模块，希望首页一次看到今天必须做什么，还能把复习卡和邮件候选置顶并设置自己喜欢的背景。

- **前置/输入**：已有本地事项、外部来源同步缓存、团队项目引用、用户布局及主题偏好；首次使用可选空布局或预设。
- **正常操作**：①进入今日首页 → ②看到今日课程、任务、复习队列、邮件建议、团队待办/审核、专注统计及通知 → ③可从卡片前往来源/查看详情/执行低风险操作 → ④切换编辑模式增删组件、拖动排序、调尺寸 → ⑤选预设和浅/深/系统主题、本地背景 → ⑥保存布局；重启后恢复。
- **快捷入口**：顶栏搜索按权限过滤日历、任务、资料、邮件、团队对象；`Ctrl+K` / `⌘K` 打开命令搜索；系统托盘或菜单栏可查看下一事项、快速建任务、启动专注、打开主界面，未获权限时不隐藏主操作入口。
- **输出**：个人自定义布局、真实模块引用、快捷创建的新对象及来源信息；偏好与团队数据隔离，隐藏组件不删除业务对象。
- **异常路径**：服务未连接、邮箱/团队权限不足、资料索引尚未完成、系统未授予通知权限、本地背景迁移失败、组件加载错误。显示“未连接/暂无事项/加载中/权限不足”等准确状态及可修复入口，不以假数据填充。
- **P0 验收**：自定义顺序与尺寸重启保持；预设可一键恢复；背景默认不上传；通知点击可跳到来源；无权项目不出现在搜索结果。

## 用户应能理解的失败恢复

每条流程都需要：①保存用户已输入但尚未提交的数据；②明确哪个环节失败、是否已经发生外部副作用；③提供重试、手工修正、取消和返回；④给出来源或版本信息；⑤在未知发送/审核/共享结果时默认避免重复执行。统一细则见 [04 状态与权限](04_STATES_AND_PERMISSIONS.md)。
