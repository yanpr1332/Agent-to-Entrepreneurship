# W2-4 · 全局交互状态、权限、安全与跨平台体验规范

> 目的：让任一模块都有统一、可信且可恢复的交互反馈。状态名属于设计语义；具体数据库枚举、接口字段与系统调用在 W3 确定。不得用“模拟已连接”“预计已完成”替代真实成功状态。

## 1. 全局组件与反馈约定

| 状态 | 显示内容 | 可操作项 | 禁止行为 | 检查实例 |
| --- | --- | --- | --- | --- |
| 首次空白 | 解释为什么没数据、需要什么权限、适合的下一步 | 新建/导入/连接/查看说明 | 假装已连校方服务或展示未经注明的虚构真实成绩 | 没有 Canvas 授权时课程区域显示「尚未连接」 |
| 加载/索引中 | 具体阶段、可能耗时、来源、合理可取消/后台执行动作 | 取消、后台继续、重试 | 点击两次导致相同外部副作用；无提示无限旋转 | 大文件 OCR/ASR 显示「排队/提取/索引/校对」 |
| 输入校验失败 | 错误字段、原因、允许的格式/范围 | 回到字段修改并保留输入 | 清空整页草稿或无解释阻止保存 | 邮件收件人空或目标日期早于开始日期 |
| 可恢复失败 | 已完成步骤、失败位置、数据有无改变 | 重试、保存草稿、手工替代、查看日志摘要 | 静默抹除原文件/版本 | 同步第 3/5 项失败且可重试 |
| 离线 | 本地仍可用部分、待同步项、上次连接成功时间 | 本地编辑、查看缓存、稍后同步 | 伪造团队发信/外部提交成功 | 无网时写邮件仅存草稿，团队消息显示未送达 |
| 权限拒绝/过期 | 发起权限的应用、目的、范围、有效期、影响 | 缩小范围、重新授权、继续使用非联网功能 | 未经许可自动扩大 Scope | AI 需要资料外传，只有本地读取许可 |
| AI 候选待确认 | 来源链接/片段、目标/动作、可信度、冲突和差异 | 接受、编辑、忽略、稍后、批量选择 | 自动发布为正式日程/任务 | 邮件解析出会议日期但年份不明 |
| 任务待审核 | 执行者、审核负责人、成果/意见、历史和状态 | 有权审核者批准/退回；执行者查看或补交 | 执行者绕过审核或个人工作台伪改 | 团队答辩资料待负责人检查 |
| 同步冲突 | 本地与远端两版本时间/来源/差异、备份 | 选择版本、合并、保留两份、暂不解决 | 自动覆盖本地唯一原件 | Windows/Mac 都修改同篇笔记 |
| 部分成功 | 成功数量、失败/跳过项、是否触发外部动作 | 查看明细、重试失败项、撤回可撤销项 | 把批处理整体误报成功 | 三条 AI 时间块只批准两条 |
| 外部操作结果未知 | 请求标识、可能已执行的风险、核查路径 | 查询远端记录、联系服务、待核验 | 自动再发邮件或重复提交成果 | SMTP/API 超时，无法断定成功与否 |
| 危险操作最终确认 | 完整目标、对象、影响、撤销难度、当前权限 | 明确确认、取消、返回编辑 | 通过默认勾选或隐藏信息绕开确认 | 邮件发信、文件原件上传/云外传、团队私有资料共享 |
| 专注限制运行 | 当前模式、实际生效/降级状态、剩余时长、允许清单 | 暂停/放行、紧急退出、恢复 | 锁死系统安全、恢复和必要通信功能 | macOS 系统不支持的限制显示为降级 |
| 用户撤权/删除后 | 将不再可用的能力、已存本地/远端数据区别 | 导出/停用/申请删除/重新授权 | 以撤销未来授权冒充已删除既有远端副本 | 停止同步不等于删除历史 PDF 上传 |

### 对话框使用原则

1. 高风险操作必须在执行前展示真实目标；禁止“只说明结果不说明发送对象”。
2. 审核/发送/分享/上传等弹窗应明确区分「取消」「保存草稿」「确认执行」，默认不替用户勾选不可逆许可。
3. 只有纯本地可撤销的低风险界面编辑可以减少确认步骤；跨账户、跨项目和云外传应保留二次审核。
4. 警告不能替代实际权限阻断或可靠错误恢复；P0 的安全门槛不能仅靠免责文案。
5. 出现网络延迟时禁用/标记重复提交按钮并保留请求 ID；重新尝试前先判断是否已有外部副作用。

## 2. 权限层次：数据来源、工作空间、操作与处理位置

### 核心分层

| 权限层 | 用户界面应显示 | 验证时需拒绝的情况 |
| --- | --- | --- |
| 用户身份及校方身份 | 独立账号、可选 jAccount 绑定、项目成员身份 | 只因绑定校园身份即获得团队管理员权 |
| 个人/团队/AI 项目空间 | 当前所在空间、归属与可见范围 | 切到团队空间后自动泄露私人资料 |
| 连接器访问范围 | 账户、文件夹/日历/页面/课程、读取/写入能力 | 连接邮箱自动拥有所有历史邮件与发送权限 |
| 本机文件/目录 | 当前项目授权的文件、目录、子目录排除、读/写开关 | 通过 `..`、软链接或跨项目路径读取未授权目录 |
| AI 运行方式 | 本地模型、云模型、所用 API Key/额度状态 | 有本地读权但自动向云模型上传内容 |
| 云端资料与同步 | 单文件仅本机/元数据/原件、设备绑定 | 从文件夹授权自动推导原件全量上传 |
| 团队共享 | 指定文件/节点、接收小组及角色、只读/编辑、撤权 | 私人知识库整体意外公开，撤权后仍能新读取 |
| 高影响外部操作 | 发送目标、修改内容、附件、最终用户确认 | AI 输出或邮件正文触发外发/删数据/提权 |

**不可跨越的交集规则**：业务模块和平台适配层必须校验 `用户当前权限 ∩ 所在项目允许范围 ∩ 操作所需授权 ∩ 实际数据处理位置许可`。前端隐藏按钮只是提示，不能成为服务端/本机权限依据。撤销后立即阻断新的受控操作；云服务已经处理或下载的副本不承诺物理撤回。

### AI 项目权限面板（P0 必填设计字段）

- 项目名称、目的、所属个人或团队、创建人。
- 逐条授权来源：文件、文件夹、排除子目录、知识库及文档集合、邮箱账号/文件夹、日历、团队项目、Git 仓库；显示最终解析后的有效范围。
- 逐项操作权限：本地读取、本地写入、调用指定外部工具、向云模型发送选定片段、发送完整原件；各项单独开关。
- 有效期：仅此操作/会话/指定截止时间/项目持续；默认只读，有效期届满可续期，支持即时撤销。
- 检查历史：显示近期数据访问或执行请求的目的、来源和结果，不把文件正文或敏感密钥写入普通日志。
- 修改/发送预览：即使已有访问范围，写入文件/发送邮件等高影响动作仍需要适当的独立审阅。

### 用户自己工作台与团队资料的关系

用户在首页看见“团队任务待办”，并不代表复制了一个私人任务；它应是同一团队对象的受控引用。私人知识向群组分享必须由用户显式挑选文档/知识节点/集合和可访问角色；AI 项目因具备文件夹读取许可也不能代用户发布共享。跨账号搜索、通知和右栏详情遵守同一规则。

## 3. 安全关键交互

### 自律锁闭

1. 启动前显示轻量/严格模式区别、实际受限软件清单、白名单、允许的系统恢复途径、预计时长与权限。
2. 严格模式仅用户明确主动启用，权限拒绝就降级为轻量模式并说明结果。
3. 运行时始终提供可达的安全退出；系统重启/崩溃/权限撤销后的清除恢复属于正式发布前 **P0 真机阻塞项**。
4. 不使用不可逆系统篡改、关闭防护工具、强制杀死用户未保存文档的应用等危险方式。
5. 专注完成后仍需用户确认任务成果，积分与现实奖励不在异常退出时伪报通过。

### 电子邮件最终发送

1. AI 只能生成/编辑草稿，邮件内容和附件不得充当控制指令。
2. 发送前完整展示 From、To、Cc、Bcc、Reply-To/原线程、主题、全文及附件列表/文件大小。
3. 在该次具体发送上点击明确确认才调用接口；新邮件、回复、全部回复、转发和修改收件人都须如此。
4. 成功须有服务端证据；失败要保留草稿；超时或未知结果必须先核查，严禁自动重发。

### 云同步与原件保护

1. 大型原件默认本地保存；单个文件选择仅本机、元数据同步或上传原件，批量选择之后可逐项覆盖。
2. 同步云端文件≠云 AI 读取授权；选择云端模型时另显示传输边界和可能的第三方留存影响。
3. 冲突保留版本及恢复操作；跨平台路径重新绑定；断网队列显示真实状态。
4. 断开连接/停止未来同步/删除本机缓存/申请删除云端副本属于四个不同动作，不应混成一个危险按钮。

## 4. 跨平台 UI/UX 一致性与差异

| 项目 | Windows | macOS | UX 共同标准 |
| --- | --- | --- | --- |
| 全局搜索 | `Ctrl+K` | `⌘K` | 聚焦搜索框、按授权范围过滤、Esc 关闭 |
| 通知与权限 | 系统通知权限及设置 | macOS 通知授权与系统设置 | 未授权明确提示，不伪造系统通知已送达 |
| 快捷区域 | 任务栏通知区域/托盘 | 顶部菜单栏状态项 | 下一事项、快速创建、专注、返回主窗口；缺权限可在应用内操作 |
| 文件选取 | Windows 文件选择器/路径 | NSOpenPanel/沙盒书签等候选 | 只能访问允许范围，文件重命名/迁移有重新绑定入口 |
| 打开文件/应用 | Windows 原生默认程序 | Launch Services 等原生行为 | 不擅自覆盖原件；能在来源文件/时间点定位 |
| 程序/网站限制 | 原生适配单独验证 | 原生适配单独验证，可能受系统能力限制 | 实际有效性、降级与紧急退出始终可见 |
| 深色模式/字体 | 系统主题、显示缩放 | Appearance、Retina | 关键文本对比、键盘操作、缩放一致 |
| 离线文件路径 | Windows 路径与本机存储 | Mac 本机路径/权限 | 数据同步不继承跨设备的本地文件夹读取权 |

**待 W3/W4 决定**：macOS 最低版本、Intel/Apple Silicon 覆盖程度、Windows ARM64 首发与否、原生锁闭能力、签名/公证、定量可用性阈值；不能在 W2 提前宣称支持所有平台细节。

## 5. 无障碍、键盘与个性化

- 所有主操作可经键盘抵达；按钮有可辨识名称，操作结果具备文字反馈，不靠颜色一种信号表达审核/错误/状态。
- 焦点应从弹窗触发处进入弹窗，Esc 可关闭非危险弹窗，关闭后返回原控件。危险操作不得因误按 Enter 就直接执行；密码、令牌、收件人不应泄露在通知预览。
- 支持系统浅色/深色和文字缩放、适当的对比度、必要的屏幕阅读器语义；拖拽改变组件顺序应有键盘替代操作。
- 背景、本机路径、主题可为设备特有偏好；跨设备背景丢失时提供重新选择，不强制上传图片。
- 提醒和通知可配置免打扰，必要的专注安全退出不因通知静默而被隐藏。

## 6. 审计和错误说明最小字段（设计预期）

建议在 UI 展示/诊断中区分：`source_type`、`source_id`、`workspace_id`、`actor`、`requested_action`、`permission_scope`、`request_id`、`client_time`、`server_time`、`sync_status`、`result_status` 和用户可理解的错误原因。W3 定义真正的数据库/协议和敏感数据最小化策略；不要求将完整邮件内容、Token、课堂录音或源文件写入日志。

## 7. 设计评审的常见反例

- 页面显示“Canvas 已接入”，其实只有静态数据或失败的 OAuth。
- AI 在仅授予一个文件夹的情况下读到其他目录或把该文件发到外部模型。
- 团队任务在个人工作台被标记完成，却绕开团队审核流程。
- 学生点击“完成作业”，误发给 Canvas 官方提交接口。
- 专注严格模式关闭应用后仍无法恢复必要程序。
- 网络超时后重复发送同一邮件，收件人收到两封。
- 取消云同步时系统误删用户唯一的本地原件。
- 自动复习误把未经确认的 AI 知识关联写成“教材事实”。

以上情形都属于明确的 P0 验收失败。对应用户旅程与测试见 [03](03_MODULE_JOURNEYS.md) 和 [05](05_W2_ACCEPTANCE.md)。
