# 项目决策记录

该文件只记录本次已确定方向和仍需确认的选项，避免讨论中的建议被误认为最终决定。

## 已确定

| 主题 | 决策 |
| --- | --- |
| 项目仓库名 | `Agent-to-Entrepreneurship` |
| 仓库公开性 | Public |
| 开源许可证 | MPL-2.0 |
| 用户群体 | 大学生 |
| 首批试点 | 上海交通大学 |
| 首发平台 | Windows 桌面优先，macOS 同期兼容与测试 |
| 产品方向 | 七大模块，围绕任务的完整闭环 |
| 上线策略 | 先形成个人管理闭环，再增强 AI 和团队协作 |
| 安全原则 | 自律限制必须可安全退出，责任告知不能替代安全设计 |
| 邮件功能 | 通过授权连接器拉取邮件，提取日历/待办；支持 AI 拟写，在用户逐次确认后发送或回复 |
| 商业化 | 不预设必须创业；名称不代表商业计划 |

## 倾向采用、尚需技术验证

- Tauri 2 + React/TypeScript + Rust 的桌面架构。
- SQLite 本地优先；可选 FastAPI/PostgreSQL/对象存储云端协作。
- Markdown 文件与 Obsidian 兼容；Whisper/FunASR 转写。
- Canvas 和 SJTU 教学 API 基础只读同步。
- 邮件只读同步与事项提取纳入 MVP；AI 邮件草稿和监督发送纳入第二阶段。具体邮箱提供商和授权方式须验证。
- 规则规划先于复杂 Agent；各平台专注限制分开实现。

## 后续待讨论

1. 正式对外显示的产品名称和品牌。
2. 开发团队规模、人员分工、仓库所有者和分支保护策略。
3. 是否所有客户端与服务端代码都采用同一个 MPL-2.0 许可证，以及第三方贡献协议。
4. MVP 的具体界面、主要导航与交互原型。
5. macOS 最低版本、Intel/Apple Silicon 支持范围及真实设备测试方案。
6. 学校 API 的具体申请与测试账号/授权流程。
7. 登录、同步、云端费用以及个人数据默认存储策略。
8. 发布地区对应的使用条款、隐私政策与风险审查。
