## 技术候选及外部条件（尚需 W3/W4 验证）

- Tauri 2 + React/TypeScript + Rust 的桌面架构。
- SQLite 本地优先；账号、跨设备同步和团队协作需要云端服务，FastAPI/PostgreSQL/对象存储只是候选实现。
- Markdown 文件与 Obsidian 兼容；Whisper/FunASR 转写。
- Canvas、SJTU 教务、学校邮箱需真实接入；应用审批和 OAuth 范围须核实。
- Google/Outlook 日历和 Notion 的 OAuth 正式发布条件与数据映射。
- 所有 P0 模块需可用，但模型硬件能力、严格专注限制、云同步容量与加密方案均须先验证。
