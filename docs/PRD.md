# 产品需求文档（PRD）V0.1

**状态：讨论版。** 下列条目是目标能力，不代表现已实现。优先级：P0 = MVP 必需；P1 = 后续重要；P2 = 远期扩展。

## 1. 日历与任务（P0）

- 日／周／月／学期视图；课程、作业、考试、个人事件、会议、项目任务按颜色区分。
- 支持单双周、周次范围、不规则上课安排、重复事件、临时调课、地点、时区。
- 统一任务字段：标题、说明、来源、课程/项目、截止时间、计划执行时段、估计耗时、优先级、依赖、完成标准、责任人、状态、附件、原始链接。
- 状态至少包含：待办、进行中、待验收（团队）、完成、延期、取消。
- 固定事件与可移动的工作时段分离；多级提醒和冲突检测。
- 对外部同步事件提供来源标记、最后同步时间、变更历史、重复项去重、手工覆盖选项。
- 支持自然语言快速录入、导入 ICS、手工编辑和离线操作。

## 2. 个人知识库（P0 基础、P1 增强）

- 导入 PDF、PPT、Word、Markdown、TXT、图片、截图、网页链接、音频/视频转写。
- 本地文件保存及检索索引；按课程、项目、主题、标签整理；支持全文搜索与双向链接。
- OCR、语音转写（Whisper/FunASR 等）和 AI 摘要作为可选流水线。
- 问答必须尽可能返回源文件、页码、段落或时间戳，区分原文、总结与推测。
- 知识点提取、复习卡片、自测题、错题/掌握度、间隔复习（P1）。
- 与 Obsidian 的 Markdown vault、URI/插件/CLI 集成；不强制依赖 Obsidian。
- 文件解析出错时仍保留原始文件及清晰的错误状态。

## 3. 专注与自律（P0 计时、P1 限制与奖励）

三种自愿模式：

1. **轻度**：计时、任务绑定、通知管理。
2. **标准**：用户定义允许列表，尽力限制分心应用/网站，随时可退出。
3. **严格**：单独确认限制范围与时长；仍须保留紧急退出与必要系统能力。

- 记录任务专注时段、暂停/中断、实际耗时、完成情况。
- 积分、等级、徽章、连贯习惯与桌宠反馈；奖励以真实产出为主，避免单纯刷时长。
- Windows 与 macOS 分别实现/验证原生限制；不能承诺不可绕过。
- 必须符合 [安全要求](SAFETY_AND_PRIVACY.md)，安全性优先于强制性。

## 4. 小组协作（P1）

- 课程小组和长期项目组两类工作空间；成员邀请、角色和权限。
- 共享看板、里程碑、团队日历、文件、版本历史、公告、讨论、基础聊天。
- 任务状态：待认领 → 已认领 → 进行中 → 待验收 → 完成，可退回。
- 负责人分配、个人认领、AI 候选分工（需确认）。
- 团队分配到某人的任务同步显示在其个人工作台；不允许未经授权修改团队事项。
- 默认只展示个人可用/繁忙状态，不公开私人日程详情。
- 会议日程、纪要、行动项、工作负载、进度汇总。

## 5. AI 智能规划（P0 规则、P1/P2 智能化）

- **基础规则引擎**：结合任务紧急度/重要度、预计时长、固定日程、休息和缓冲安排可用时段。
- **动态重排**：新任务、延期、调课、任务超时后建议调整；用户可接受、拒绝、撤销。
- **知识库联动**：根据考试、掌握度、资料与错题建议复习顺序和学习活动。
- **Agent 增强**：自然语言创建事项、会议纪要转任务、周报、资料整理等；外部发送、删除、共享或大范围调整前必须确认。
- 说明规划依据；用户可锁定时间块和手工调整；无 AI 时基础逻辑仍可使用。

## 6. 接入与扩展（P0 基础、P2 插件）

- 统一连接器接口：Canvas、交大教务 API、ICS，后续可添加更多高校、日历与云服务。
- 同步状态、权限撤销、数据来源、失败重试、手动导入后备路径。
- 事件自动化（例如新作业 → 任务 → 提醒 → 规划）；第三方插件/自定义字段/模板后置。
- 数据备份、恢复、导出（尽可能使用开放格式）、账户及设备间同步策略。

## 7. 个人工作台（P0）

- 今日/本周日程、最紧急任务、当前推荐事项、学习/专注时间与团队待办。
- 统一收件箱：快速收集文本、截图、网页、语音、邮件片段等，再进行归类。
- 早晨简报、每日核对、每周复盘、延期与冲突提示。
- 自定义卡片、主题、快捷键和全局快速输入（后续增强）。

## 跨模块基本流程

`信息接入/用户输入 → 统一任务或资料 → 日历/知识库关联 → 规划 → 专注/协作执行 → 状态与耗时记录 → 复盘/调整`

## 非功能需求

- 本地优先、断网可用；云协作为可选增强。
- Windows/macOS 共用核心数据结构和主要 UI；双平台持续集成与真实设备测试。
- 个人数据与团队数据隔离、最小权限、可导出、可删除、可恢复。
- 不将 WSL、Obsidian、云端 AI 或任何单一第三方平台作为必需依赖。
- 高风险系统操作可撤销、可审计、失败时安全恢复。
