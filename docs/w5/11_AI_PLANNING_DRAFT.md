# W6-13: 选择性 AI 学习规划草稿

本轮新增 AI 页面上的只读结构化学习建议，复用已有的加密 Key、每日请求额度、一次性两分钟确认及固定 OpenAI HTTPS 端点。

## 用户流程
1. 仅在本地展示个人任务；不会在打开页面时发起 API 请求。
2. 用户主动勾选 1–8 个可见且未完成的任务，并选择七天窗口开始日期。
3. 预览前重新读取本地任务并校验选择，仅组织任务 ID、标题、截止日、优先级。**不传描述、Canvas 来源链接、邮件、知识文档和团队内容**。超长请求拒绝。
4. 用户核对完整原文及模型后，独立点击确认才会发出可能收费的请求。
5. 返回数据必须为严格 JSON；校验任务 ID、去重、日期、时间、时长、理由与字段白名单。任一块无效即整体拒绝。
6. 合法候选仅供 AI 页面查看，**不自动创建正式任务或时间块**。

## 风险与尚未实现
- 模型不掌握固定课程/其他日程，当前只是结构和时间边界验证，不能代表排程无冲突。
- 候选保留于当前 React 页面内存，离开页面后不会持久化。
- AI-003 的只读草稿部分已实现；AI-004 的 Main 进程权威任务一致性校验、日程冲突检查、选择性写入与撤销，留给后续 PR，不得宣称完成。
- 不使用真实 Key 做自动化测试。Windows/macOS CI 通过、真实个人设备的用户界面验收仍需分别确认。
