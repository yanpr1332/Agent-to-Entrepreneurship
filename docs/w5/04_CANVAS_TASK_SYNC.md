# W5-4 Canvas 自动同步、任务可见性与六个月保留策略

状态：产品决策已确认；本文件定义目标行为。当前 PR 代码仍处于逐条导入/手动同步阶段，自动同步与可见性功能需按本文继续实现，不能将目标规格误报为已交付。

## 已确认的产品决策

1. 首次成功连接 Canvas 后，默认同步用户当前所有有权访问的当前课程及其作业；不要求逐条点击导入。
2. 软件运行期间定时同步；应用启动/连接成功后立即同步，并提供手动立即同步。首版不要求为同步而强制常驻后台。
3. 用户可以逐条选择已同步任务「显示 / 隐藏」。隐藏只影响本地工作台、任务列表和日历的展示，不代表从 Canvas 删除，也不改变 Canvas 的提交/成绩状态。
4. 被隐藏的 Canvas 任务及其来源映射在本机数据库保留六个月；界面必须明确提醒保留期限和到期清理规则。
5. 隐藏任务在六个月保留期内仍保留外部身份和去重记录。自动同步不得因为任务隐藏而重新显示它，也不得重复创建副本。
6. 用户可以在保留期内恢复显示。恢复后继续参与同步。
7. 六个月到期后，隐藏任务的本地任务内容和映射记录可以清理；再次从 Canvas 拉取到该作业时，按当前课程同步规则重新创建任务。不得清理仍显示的任务。
8. 完成状态、个人备注、优先级，以及用户手动修改的标题和截止日期均属于个人字段，远端同步不得覆盖。

## Canvas 自动同步行为

- 连接并验证成功后，读取当前用户身份、当前活跃课程，再逐门读取可见作业。
- 对所有未屏蔽且可访问的课程默认开启同步；如果后续增加课程级屏蔽，课程级屏蔽必须与单条任务隐藏分开建模，不能混为一项。
- 新发现的作业自动建立本地任务和来源映射。
- 已存在作业按外部自然键匹配：Canvas 实例 origin + Canvas account ID + course ID + assignment ID。
- 远端作业标题/截止时间更新时，只更新尚未被用户修改的字段。
- 远端删除或暂时不可见时，标记 missing / last-seen 状态并提示用户；不因一次 API 缺失就删除本地任务。
- 同步失败不清空上一次成功数据；保留 last successful sync、错误类型、下次重试时间。
- 分页、速率限制、超时和部分课程失败都必须单独处理；一个课程失败不能阻断其他课程同步。
- Token 仍只由 Electron Main 使用系统凭据加密保存。个人 Token 仅限开发者本人本地验证；多人正式接入须学校 Developer Key + OAuth。

## 隐藏与六个月保留

任务的展示状态是本地个人偏好，不是远端 Canvas 状态：

| 用户动作 | 本地行为 | 下次同步 |
|---|---|---|
| 显示 | visible=true | 正常更新受远端控制的字段 |
| 隐藏 | visible=false，记录 hidden_at 和 retention_expires_at | 不展示、不重新创建、不覆盖个人内容 |
| 恢复显示 | visible=true，清除隐藏计时 | 恢复正常同步 |
| 隐藏满六个月 | 展示清理提醒，允许在到期前恢复 | 到期清理隐藏任务及映射；若仍属于同步范围，之后可重新发现 |

**用户提醒文案（必须出现在界面）：**

「已隐藏的 Canvas 任务会在本机保留六个月，之后自动清理。你可以在此期间恢复显示。隐藏不会删除 Canvas 上的原始作业。」

提醒应在用户首次隐藏任务时显示；在隐藏任务管理区显示每条任务预计清理日期；到期前 30 天再次提醒。清理前不得误删显示中的任务。

六个月按隐藏时间计算，使用明确的 UTC 时间戳；不要把「远端最后出现时间」当作隐藏起始时间。

## 单一任务数据源与冲突规则

本地 SQLite tasks 仍是个人任务的唯一权威数据源；Canvas 数据作为外部来源快照和来源映射，不另建一套平行任务库。

个人可编辑字段：description、priority、completed、visible，以及用户手动编辑过的 title / due_date。
远端管理字段：remote_title、remote_due_at、source_url、last_synced_at、missing 状态。
字段是否被手动编辑必须通过显式 override 标志或等价的字段级元数据保存；不能只用「当前值是否等于上次远端值」推断，因为用户可能把字段改回相同值。

## 跨接入统一自动同步原则

Canvas 不是特例。其他外部接入也应采用统一同步模型，默认在用户授权和选择同步范围后自动增量同步，而不是所有条目都要求用户逐条点「导入」。

| 接入 | 默认自动收集的对象 | 用户控制范围 | 写回外部系统 |
|---|---|---|---|
| Canvas | 已授权当前课程的作业、截止时间 | 课程范围、单条任务显示/隐藏 | 默认只读，不写回 |
| 邮箱 IMAP | 用户授权邮箱中的邮件元数据；按规则识别可能的任务候选 | 文件夹/标签/时间范围、候选任务确认与忽略 | 读取不写回；发送必须逐次确认 |
| 日历（后续） | 用户选择的日历与事件 | 日历范围、事件显示/隐藏 | 默认只读，编辑/邀请需明确确认 |
| 文件/云盘（后续） | 用户逐文件选择范围内的元数据和内容索引 | 文件夹/单文件同步范围、排除项 | 不自动修改或删除源文件 |

统一同步能力应提供：授权状态、同步范围、自动/手动触发、频率、上次成功时间、下次同步时间、错误与重试、增量游标、来源追踪、重复去重、用户覆盖字段、撤销授权后的处理策略。大文件（PDF、录音等）必须沿用逐文件授权/同步选择，不得因连接云盘而默认全量上传。

邮箱中的邮件不应全部直接变成任务：应自动同步/索引授权范围内的邮件元数据，再由规则或 AI 生成任务候选；低置信度候选由用户确认。自动同步不等于自动发送邮件。

## 推荐首版同步节奏

- 授权/首次连接成功：立即执行一次全量基线同步。
- 应用启动：若距上次成功同步已超过频率阈值，执行增量同步。
- 应用运行中：按接入源分别设置可配置间隔；Canvas 首版建议 30 分钟，邮箱建议 5–15 分钟（遵循服务商限制）。
- 用户手动刷新：立即同步，仍遵守限流。
- 网络错误：指数退避；401/403 转为需要重新授权，不无限重试。
- 关闭主窗口后不保证同步；除非用户启用后台驻留模式，不要求常驻后台。

## 数据库实现与验收要求

建议 SQLite v3 增加：visible、hidden_at、retention_expires_at、field override 标志、last_seen_at、sync_status 等字段，并建立 tombstone / exclusion 语义。迁移必须支持当前 v2 数据库，保留现有任务 ID、备注、完成状态与来源关系；迁移应有回滚或备份策略。

自动化验收至少覆盖：
- 首次同步会为全部当前课程的可访问作业建立任务；
- 重复同步不重复创建；
- 隐藏任务在六个月内始终隐藏且不重复创建；
- 恢复显示后恢复更新；
- 到期清理只处理隐藏条目；
- 30 天到期提醒、六个月到期行为；
- 用户字段覆盖标志持久化；
- 单课程失败不阻断其他课程；
- 分页、速率限制、撤权、部分同步和断网恢复；
- Windows/macOS 数据库迁移与自动同步测试。

本文件描述产品目标与验收标准，不表示上述所有功能已在当前 PR 实现。
