# W5-5 Canvas 默认自动同步、隐藏与六个月保留

状态：**代码已进入待审阅 PR；CI 与真实设备验收分别记录**。本文区分已经实现的代码与尚需验证的产品能力。

## 已实现的产品决策

- 连接开发者个人 Canvas 账号后，Electron Main 在后台读取当前活跃课程，逐门拉取有权访问的作业，将所有未屏蔽课程的新作业自动建为本地 M1 任务；不再要求用户逐条点击导入。
- 桌面应用启动时检查同步；应用窗口存在期间每 30 分钟执行一次；可点击「立即同步所有课程」。不强制常驻后台。
- 单个课程可以暂停/恢复自动同步。暂停课程**不删除已同步任务，也不自动隐藏**这些任务；用户可逐条隐藏。
- 单条 Canvas 任务可隐藏或恢复。普通日历与工作台不显示隐藏项；「隐藏任务」入口中显示隐藏记录和预计清理日期。
- 隐藏任务与来源映射在 SQLite 保留**六个日历月**，隐藏时弹出确认提示并显示持续提醒；到期前 30 天在日历页提示；下次应用启动或同步时自动清理**已到期的隐藏任务**。应用长期未启动时不会在关机期间自行清理。
- 隐藏不删除 Canvas 的远程作业。六个月内源映射继续存在，自动同步不会重新导入或覆盖隐藏记录；恢复后重新参加同步。
- 更新源数据时保存个人备注、完成状态、优先级和用户明确修改过的标题/截止日期。使用明确字段覆盖标志，而不仅靠与远端快照的字符串比较。
- Canvas 只读，不修改或提交学校的作业。个人 Token 只用于**开发者本人本地验证**，以系统加密保存，不写入日志、任务表、仓库或云端。

v1 → v3、v2 → v3 均在 SQL 事务内完成，失败回滚；既有 `tasks` 数据、个人备注与专注记录保留。**生产级迁移前自动快照备份/一键恢复仍待实现**，属于后续工程任务。

## 同步调度、安全与失败处理

- 每个账号实例只有一个同步执行中的任务；重复点击会复用同一同步请求，避免并发写入。
- 单门课程 HTTP 失败不阻断其他课程；失败课程已有数据不会被删除。
- 断开连接时撤销正在运行的同步任务的写入许可，清除本机加密 Token，已同步本地任务仍保留。
- Canvas REST 仍使用认证 Header、同源分页、禁止自动重定向和请求超时；本机数据不自动上传。
- 失败原因显示为不包含 Token 或远端原始响应体的简要消息。
- 同步状态显示上次成功时间与部分失败数量；软件运行期间不要求系统托盘驻留。
- 当前任务截止日期是用户本机时区日期；未来跨设备云同步需要单独处理时区配置。

## 交互和保留提醒

隐藏时文案：

「隐藏这条 Canvas 任务？它会在本机保留六个月，之后自动清理。保留期间你可以在隐藏任务列表中恢复显示。隐藏不会删除 Canvas 上的原始作业。」

隐藏管理列表必须标明预计清理日期；距清理日期 30 天内显示提醒。普通本地手建任务的「删除」仍为真正删除。

**保留期限的含义**：用户隐藏后的六个日历月，不是从作业截止日期或上次同步日期算起。恢复显示会清除到期清理标记。六个月到期后若仍属于课程同步范围，再次发现此作业可能重新创建新任务（而不是保留超期的旧数据）；后续可设计永久排除策略。

## 跨连接器自动同步原则

Canvas 的「授权后自动拉取 → 本地来源映射 → 允许隐藏/排除 → 同步状态 → 失败重试」应作为其他接入的设计基线。**不等于已完成通用同步 SDK 或邮件/日历/云盘自动同步。**

- 邮箱：自动读取用户选定邮箱与文件夹范围的邮件元数据，并产生待确认任务候选；**不自动把所有邮件变任务**，发送必须逐次人工确认。
- 第三方日历：同步用户授权范围内的日历与事件；个人覆盖字段保护，外部写操作另行确认。
- 云盘：同步用户明确选择的文件夹范围、元数据和索引；PDF、录音等大文件保持单文件授权与传输控制，不能因授权连接而上传全部内容。
- 统一抽象下一步应包含：数据来源/身份、最小授权范围、轮询与限流、游标、去重与幂等、用户字段覆盖、排除和留存、状态/重试/错误告警、取消与撤权。

## 自动化验收

本 PR 的 Vitest 覆盖：
- 所有活跃课程自动导入 + 重复同步幂等；
- 课程同步开关；
- 隐藏后保留、不重新显示、不再次导入；
- 恢复显示后继续更新；
- 到期清理只删除隐藏项，按六个日历月精确计算；
- 即便用户把日期改回原值，也应保护明确人工编辑字段；
- 课程部分失败继续其余课程；
- 断开前进行中的同步不可继续写入；
- v2 → v3 迁移后旧任务及来源仍在；
- 既有 v1 → 最新版本的测试。

仍待真实设备/真实学校账号验证：Windows 与 macOS Electron 启动、Canvas 登录与实际作业读取、后台运行 30 分钟调度、临近到期提醒 UX、Token 撤权/网络断开后的恢复。CI 模拟 HTTP 不代表学校 API 验收已通过。
