# W6-12 OpenAI Provider：用户授权、单轮问答、安全调用（开发版）

> 功能代码提交在独立 PR 中。真实 API Key、真实计费、桌面端登录和 UI 操作仍待用户本机验收。所有自动化测试使用虚构测试 Key 与模拟 HTTPS Response，绝不消费真实账户额度。

## 已实现

- 桌面新增独立「AI 学习助手」页面，**不替换**现有「学习规划（离线规则）」页面；后者目前仍不使用 AI。下轮 PR #13 再研究受控的 AI 结构化学习规划草稿。
- 首个 Provider 固定为 **OpenAI Responses API** `POST https://api.openai.com/v1/responses`，不允许用户提供任意主机/IP/代理地址。使用 Node 原生 fetch，**无新 npm 依赖**，请求只在 Electron Main 进程发起。
- 用户自行选择 GPT 模型 ID、在设备界面输入自己的项目 API Key；只有在 Electron `safeStorage` 系统安全加密可用时才将 Key 加密存入 `userData/ai-personal.enc`，拒绝 Linux `basic_text` 弱加密退化。Renderer 不持久化 Key，不返回解密值或 Key 部分给 UI，数据不写入日志或 GitHub。
- **连接不会自动验证或消费收费 API 请求。** 已连接表示 Key 被保存，**不保证模型与 Key 可用**。
- 单次问题最长 2000 字符，首先点击「预览」，Main 生成仅存在内存、有效两分钟的一次性审批 ID，UI 清楚展示即将发送的全文和模型；点击「确认发送」后才发出一次 HTTPS 请求。任何重复/过期/失效审批 ID 均拒绝；取消或更换 Key 会清空未使用审批并尝试中止执行中请求。
- API 请求显式 `store:false`、`tools:[]`、`max_output_tokens:512`，不开启 Web 搜索、MCP/计算机、文件访问、第三方工具、服务器会话链或自动循环；单轮只传这次用户审阅的文字，不自动附带先前聊天、Canvas、邮件、知识库全文、计划/个人任务或共享小组内容。
- 25 秒请求超时、响应最多 192 KiB、失败不自动重试。外部 HTTP/网络异常对 UI 使用固定、脱敏错误摘要，**不转发原始供应商错误体**。
- 本机 `ate-ai-usage.sqlite` 仅保存 UTC 日期、已确认请求尝试次数、服务商返回的输入/输出 token 数，不保存提问、回复或 API Key。每天最多 12 次已确认请求（包含失败/未知结果），断开或重新连接**不会重置**当日额度。此值是**本机调用次数限制，不是账单金额上限**。不同设备、其他应用和服务商的花费不受此限额保护。模型单价需用户按 OpenAI 当前 API 价格自行核对。
- 页面回复以普通文本渲染，不执行 Markdown HTML 或模型生成的代码；聊天只在当前 React 页内存中暂存，退出页面不保留历史。AI 不会向任务、日历、邮件、知识库和云端协作写任何数据。
- 提供「断开并删除本机 Key」「取消预览」「尝试中止当前请求」；如果 HTTP 结果不确定，提示可能仍产生费用并由用户查看服务商用量，不进行自动重试。

## 当前界面必须展示的告知

调用模型是**用户主动触发的对外数据传输**，可能计费。即使 `store:false`，API 服务商仍需处理请求，数据处理、保留和审计遵循其适用政策，不能把该标志解释为「第三方完全不处理数据」或「完全零保留」。软件不提供真实金额计算或总支出担保。请不要上传校园邮箱密码、Canvas Token、API Key、真实隐私数据或学校敏感文件。

**官方技术参考**：https://platform.openai.com/docs/api-reference/responses
**价格参考**：https://platform.openai.com/pricing

## 自动化测试

- 模型 ID 与 Key 格式、字段白名单、提示长度及恶意换行拒绝；
- Electron OS 加密适配器失败/明文退化拒绝保存、加密文件不包含可读 Key、主动删除；
- 模拟 HTTPS Request 捕获：只允许官方地址、Bearer Main Key、`store:false`、`tools:[]`、单轮用户问题、512 token、禁止自动附带 Canvas/邮箱；
- 只提问预览时不调用服务商，不增加使用次数；确认 ID 一次使用，替换预览使旧 ID 失效；
- 连接/断开不会产生模型请求、当日配额持久化并阻止越限、失败/网络未知不会自行重试；
- 模拟未完成、超大响应、鉴权失败时不显示原始包含凭据的内容；
- GitHub Actions Windows/macOS TypeScript、Vitest 与 Electron production bundles。

## 真实设备验收（待用户决定）

1. 将此 PR 审阅合并后，由用户**自主选择**是否在个人设备上填写测试项目的 API Key（**不要向 ChatGPT 或 GitHub 提供密钥**）。建议限制测试项目预算，并关注价格。
2. 确认点击保存不会消耗 API；提交一个无敏感信息的短问题，先观察预览，再明确确认；验证返回文本、token 计数和平台使用量。
3. 多次刷新/重启检查本机加密 Key 的状态和已使用请求次数；使用过期预览、取消预览、断开 Key 验证不发送。
4. 使用错误 Key/不可用模型检查失败提示；请求未知或中途取消后先查看 API 用量，避免误双发。
5. 验证没有把对话答案自动写进正式任务、日历、知识库或团队协作。

## 明确不在这一轮内

- AI 生成规划日历候选、工具调用、跨模块资料上下文、多轮持久会话、知识引用/检索增强、PDF AI 摘要、AI 自动识别邮件正文、费用实时估算/硬性金额上限；
- 第二家 AI Provider、自定义 API endpoint、代理、本机推理与账户多设备同步；
- 真实账户验证、任何外部 API 密钥创建与分发、macOS 签名/公证；
- 自动安装/部署、访问用户电脑、RDC、合并 main。

下一轮 PR #13 将通过额外的**逐项选择上下文、原文预览和结构化结果校验**，使模型只输出候选草稿，之后仍须用户在既有规划引擎中复核和选择性应用。
