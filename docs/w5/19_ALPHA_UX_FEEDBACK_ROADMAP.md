# Alpha 本地验收反馈与分阶段开发路线（2026-11-19）

> 来源：Windows Electron 首轮真实使用反馈。**“本轮代码已实现”不等于“真实 GUI 已通过”。** 本轮及后续均要求单独 PR、双平台 CI、实际设备复核。状态以事实为准，不得把设计文档冒充已实现。

## ALPHA-UX-001：本轮基础交互（代码已提交，Windows/macOS CI 已通过；最新提交及本地 GUI 复测仍须核对）

| 用户反馈 | 本轮改动 | 手工验收标准 |
| --- | --- | --- |
| 勾选完成的对号含义不明 | 可见标记完成、已完成/撤销的文字状态 | 任务可完成及撤销，重启后仍一致 |
| 新建任务小窗口不能隐藏 | 默认不显示右侧面板，显式新建任务按钮；编辑时展开，允许收起 | 面板关闭时日历全宽，重新编辑正常，不丢失已保存数据 |
| 不管切换哪天看起来都像今天 | 顶部独立显示选中日期+星期；今天另作标识，回到今天另设按钮 | 点击非今天、切月/周/日，日期高亮与下方任务课程同步 |
| 课程和任务时间修改不直观 | 课程单次日期/时间编辑入口明确；任务原有截止日期编辑保留，说明区别 | 编辑已有任务截止日；修改手动课程本次的日期、开始、结束 |
| 专注时间不可自定义 | 1–180 整数分钟自定义输入，保留常用预设 | 可输入 2、90、180；0、181、1.5 无法开始；可暂停和继续 |
| 主题按钮找不到 | 左侧底部增加带文字的主题下拉：浅色/深色/跟随系统 | 切换、重启保留模式；系统模式跟随操作系统 |

本轮不改 SQLite schema、外部连接器、隐私/权限以及登录方式。**尚无用户在最新 PR 分支的真实 Windows GUI 验收结果。**

## ALPHA-TIME-002：任务、课程与专注时间模型（部分实现）

PR #27 已实现**专注子范围**：自定义标题、历史记录更名、真实起止时刻、SQLite v5 迁移与日/周/月日历展示，详情见 [20 专注实际时段实施与验收](20_ALPHA_TIME_002_FOCUS_CALENDAR.md)。**任务截止/执行时段、整组课程编辑和暂停段精细明细仍未实现。**

- 任务原有 dueDate 是“截止日期”，不是占用的具体时间；后续支持可选截止时刻和多个计划执行时间块。Canvas 原始数据、用户本地覆盖和个人学习计划分开存储，隐藏保留六个月逻辑不得破坏。
- 周重复课程支持“只改本次”“从本次起”“全系列”编辑，明确 Canvas 只读和 ICS 导入来源的区别；考虑跨月、时区、夏令时、学习计划冲突，禁止静默覆盖已确认安排。
- 专注标题和真实起止时刻（**PR #27 已实现**）；逐段暂停记录及编辑备注（**未实现**）。目前有效时长独立保存；更改标题不会发放积分。
- 专注点击「保存/记录」后生成**真实执行**日历记录（**PR #27 已实现**，并非倒计时自动无确认入库），与学习计划区分。任务关联、崩溃恢复和复杂时钟变更处理仍未实现。
- 本轮采用 SQLite v4→v5 user_version 迁移，初始化前自动生成校验过的快照；更完整恢复流程与 UI 仍待完成。禁止覆盖用户真实库。

## ALPHA-TIME-003：手动任务执行时间与单段修改（代码已提交，GUI 待验收）

PR #28 在既有学习规划体系中实现：手动创建任务执行时间、同任务多段安排、单段已确认时间修改/删除、与固定课程冲突校验，以及 `ate-plans.sqlite` v1→v2 迁移前快照。**任务 dueDate 不受影响**，Canvas 的原始截止日期不被覆盖。完整边界与集中测试步骤见 [21 手动时间安排与修改](21_ALPHA_TIME_003_TASK_SCHEDULES.md)。

仍待开发：任务具体截止时刻、计划/专注自动绑定、拖拽时间线等；重复课程批量修改转由 ALPHA-TIME-004 跟进。这一 PR 的自动化测试结论与用户 GUI 验收应分开记录。

## ALPHA-TIME-004：重复课程批量修改（代码已提交，GUI 待验收）

PR #29 实现手动重复课程「仅本次 / 从本次起 / 整个系列」范围编辑，批量改名、日期平移、起止时间，整组验证与已确认学习计划的冲突并**原子回滚**。不改 Canvas/ICS 来源、任务截止或专注记录，无新数据库迁移。详细范围与 GUI 用例见 [22](22_ALPHA_TIME_004_COURSE_SERIES_EDIT.md)。这并不表示拖拽日历和其他计划批量编辑已完成。

## ALPHA-KB-003：知识库安全预览与本地容错搜索（代码已提交，GUI 待验收）

PR #31 增加 HTML/LaTeX UTF-8 原文导入、Markdown/HTML/LaTeX **受限且不执行的安全阅读预览**、源码切换、MathML 基础公式，以及离线 FTS5 候选+有限编辑距离的拼写容错搜索；保留来源文档、证据片段、版本和 PDF 页码。完整 TeX 引擎、复杂 HTML CSS、专业搜索排序和 AI 语义检索**仍未实现**。具体见 [24 知识库升级与安全边界](24_ALPHA_KB_003_SAFE_PREVIEW_SEARCH.md)。

### ALPHA-KB-004：本地检索混合排序与自愿 AI 单段解释（PR #32）

新增精确+容错结果合并，复用现有两步确认的 AI Provider，在用户选择**一段原文并完整预览实际发送内容**后才可请求单轮辅助解释；回答只作为参考，附有可追溯的本机原文，但不自动存入复习卡。默认不上传私人文档。**这不是全文 AI 向量语义搜索，也不支持多文档 RAG。** 集中测试与隐私规则见 [25](25_ALPHA_KB_004_AI_SOURCE_EXPLANATION.md)。

### ALPHA-KB-005：精确 + 模糊 + **本地向量语义搜索**（已列入后续开发，未实现）

已根据用户新要求明确列入 Backlog：保持现有 SQLite FTS5 精确检索与字符编辑距离容错检索，再增加 **用户可选、可断网运行的本地 embedding 向量检索**，三路融合、去重和原文证据跳转。优先评估 multilingual-e5-small（中英多语言）与 bge-small-zh-v1.5（中文/低资源），分 PoC、离线索引、三路融合三个子阶段。**模型尚未下载/集成，功能尚未实现；当前 PR #32 不包含它**。详细难易度、许可证、模型体积、Electron 兼容与集中验收见 [26 可行性及分阶段方案](26_ALPHA_KB_005_LOCAL_SEMANTIC_SEARCH_FEASIBILITY.md)。

### 剩余的知识库扩展（仍未实现）

- Markdown、HTML、LaTeX（.tex）需支持**安全阅读预览与原文切换**。Markdown 包括表格/代码块/数学公式；HTML 禁止脚本、事件属性、危险 URL 和远程资源；LaTeX 优先安全的公式及基础环境，不运行任意 TeX 命令或外部编译器。
- 升级导入器、提取器、索引器前必须限制文件大小与解析资源；不可信文本不得未经清洗插入页面。保留来源路径、文档版本、PDF 页码等证据。
- 首选离线容错搜索（少量拼写、空格、标点差异）及可解释排序；随后考虑可选本地语义索引或用户明确授权的 AI 搜索。默认不上传私人资料，AI 生成答案必须指回真实原文片段。

## ALPHA-TEAM-004：自律积分小组排行榜（未实现）

- 小组成员**主动加入**周排行榜；展示有效专注时长、积分及坚持天数，不公开他人的学习标题和精确时间表，允许退出或匿名。
- 防刷分需要幂等会话、有效计时边界、每日计分规则、异常设备时钟处理；可编辑的标题、备注、日历时间块不能直接加分。
- 依赖团队账户、Supabase RLS、真实五人协作验收与隐私设计通过后再上线。

## ALPHA-APP-005：稳定性与资源（未完成）

- 退出时的 libpng warning: iCCP: known incorrect sRGB profile：调查图片资源和 ICC Profile，记录是否同时发生崩溃；单独的警告不等于数据库损坏。
- 安装包、备份恢复 UI、Electron 沙箱异常、真实账号/授权与安全检查，仍是 Alpha 发布前的独立风险。

## 验收证据要求

1. PR 包括变更文件、单测与 Windows/macOS CI 证据；不能把 CI 当真人点击。
2. 用户用独立 ATE_USER_DATA_DIR 运行并对照 [README](../../README.md) 点击复测，保存脱敏步骤与截图。
3. 涉及 SQLite 迁移、Canvas、邮件、AI 时先用测试数据核对数据完整性、授权和回滚。
4. 后续每轮从本路线图明确认领范围，不把未实现想法标成“完成”。
