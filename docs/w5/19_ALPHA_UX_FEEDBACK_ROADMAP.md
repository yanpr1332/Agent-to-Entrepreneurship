# Alpha 本地验收反馈与分阶段开发路线（2026-11-19）

> 来源：Windows Electron 首轮真实使用反馈。**“本轮代码已实现”不等于“真实 GUI 已通过”。** 本轮及后续均要求单独 PR、双平台 CI、实际设备复核。状态以事实为准，不得把设计文档冒充已实现。

## ALPHA-UX-001：本轮基础交互（代码已提交，CI 和本地复测待完成）

| 用户反馈 | 本轮改动 | 手工验收标准 |
| --- | --- | --- |
| 勾选完成的对号含义不明 | 可见标记完成、已完成/撤销的文字状态 | 任务可完成及撤销，重启后仍一致 |
| 新建任务小窗口不能隐藏 | 默认不显示右侧面板，显式新建任务按钮；编辑时展开，允许收起 | 面板关闭时日历全宽，重新编辑正常，不丢失已保存数据 |
| 不管切换哪天看起来都像今天 | 顶部独立显示选中日期+星期；今天另作标识，回到今天另设按钮 | 点击非今天、切月/周/日，日期高亮与下方任务课程同步 |
| 课程和任务时间修改不直观 | 课程单次日期/时间编辑入口明确；任务原有截止日期编辑保留，说明区别 | 编辑已有任务截止日；修改手动课程本次的日期、开始、结束 |
| 专注时间不可自定义 | 1–180 整数分钟自定义输入，保留常用预设 | 可输入 2、90、180；0、181、1.5 无法开始；可暂停和继续 |
| 主题按钮找不到 | 左侧底部增加带文字的主题下拉：浅色/深色/跟随系统 | 切换、重启保留模式；系统模式跟随操作系统 |

本轮不改 SQLite schema、外部连接器、隐私/权限以及登录方式。**尚无用户在最新 PR 分支的真实 Windows GUI 验收结果。**

## ALPHA-TIME-002：任务、课程与专注时间模型（未实现）

- 任务原有 dueDate 是“截止日期”，不是占用的具体时间；后续支持可选截止时刻和多个计划执行时间块。Canvas 原始数据、用户本地覆盖和个人学习计划分开存储，隐藏保留六个月逻辑不得破坏。
- 周重复课程支持“只改本次”“从本次起”“全系列”编辑，明确 Canvas 只读和 ICS 导入来源的区别；考虑跨月、时区、夏令时、学习计划冲突，禁止静默覆盖已确认安排。
- 专注标题支持开始前自定义、结束后改名称/备注；计时事件独立保存真实开始/结束、暂停区间和有效时长，避免仅靠结束时间倒推开始日期。更改标题/备注不能额外获得积分。
- 专注结束后自动产生**真实执行**日历记录，与学习计划区分；可关联任务，也可独立学习。跨日、暂停、去重和时间错误均须有测试。
- 数据库迁移采用 user_version、迁移前快照、备份及可恢复测试，不能覆盖用户真实库。友好的备份恢复 UI 仍待完成。

## ALPHA-KB-003：知识库渲染与搜索（未实现）

- Markdown、HTML、LaTeX（.tex）需支持**安全阅读预览与原文切换**。Markdown 包括表格/代码块/数学公式；HTML 禁止脚本、事件属性、危险 URL 和远程资源；LaTeX 优先安全的公式及基础环境，不运行任意 TeX 命令或外部编译器。
- 升级导入器、提取器、索引器前必须限制文件大小与解析资源；不可信文本不得未经清洗插入页面。保留来源路径、文档版本、PDF 页码等证据。
- 首选离线容错搜索（少量拼写、空格、标点差异）及可解释排序；随后考虑可选本地语义索引或用户明确授权的 AI 搜索。默认不上传私人资料，AI 生成答案必须指回真实原文片段。

## ALPHA-TEAM-004：自律积分小组排行榜（未实现）

- 小组成员**主动加入**周排行榜；展示有效专注时长、积分及坚持天数，不公开他人的学习标题和精确时间表，允许退出或匿名。
- 防刷分需要幂等会话、有效计时边界、每日计分规则、异常设备时钟处理；可编辑的标题、备注、日历时间块不能直接加分。
- 依赖团队账户、Supabase RLS、真实五人协作验收与隐私设计通过后再上线。

## ALPHA-APP-005：稳定性与资源（未完成）

- 退出时的 libpng warning: iCCP: known incorrect sRGB profile：调查图片资源和 ICC Profile，记录是否同时发生崩溃；单独的警告不等于数据库损坏。
- 安装包、备份恢复 UI、Electron 沙箱异常、真实账号/授权与安全检查，仍是 Alpha 发布前的独立风险。

## 验收证据要求

1. PR 包括变更文件、单测与 Windows/macOS CI 证据；不能把 CI 当真人点击。
2. 用户用独立 ATE_USER_DATA_DIR 运行并对照 [README](../../README.md) 点击复测，保存脱敏步骤与截图。
3. 涉及 SQLite 迁移、Canvas、邮件、AI 时先用测试数据核对数据完整性、授权和回滚。
4. 后续每轮从本路线图明确认领范围，不把未实现想法标成“完成”。
