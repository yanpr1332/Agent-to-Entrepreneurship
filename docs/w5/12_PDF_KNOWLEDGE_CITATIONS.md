# W6-15 本地知识库 PDF 可选择文本、逐页出处与安全迁移

状态：GitHub 独立依赖 PR，真实 Windows/macOS 设备验收尚未进行。PR #14 应先审阅合并；该 PDF PR 以 #14 的恢复分支为基础，不绕过用户的 main 合并审批。

## 实现范围

1. **新支持纯本地 PDF 文字提取**：只能由用户使用 Electron 原生文件选择器挑选 PDF（最多 12 MiB、120 页）；不接受 Renderer 传入任意磁盘路径，不扫描文件夹或学校账号。支持原有 UTF-8 Markdown/TXT（最多 2 MiB），仍不改变原文件。
2. 固定并锁定 Mozilla `pdfjs-dist@6.5.438`（Apache-2.0），在本机 Electron Main 进程按需加载，以 `getTextContent()` 逐页提取真实可选择文字。2026 年披露的 PDF.js 脚本执行漏洞已在 6.2.108 修复，本仓库采用更高的固定版本；应用同时设置 `isEvalSupported:false` 和 `enableScripting:false`，不使用 PDF Viewer 执行嵌入脚本。依赖包通过 `package-lock.json` 固定版本和 tarball SHA-512；不会从 CDN 拉取代码运行。
3. 导入时检查 PDF 文件扩展名、普通文件/非符号链接、PDF 文件头、二进制大小和提取文本长度（最多 2 MiB），限制输出单页字符和总页数。**不做 OCR**：扫描图像 PDF 没有可选文字时明确报错，禁止把图片内容冒充已识别文本。
4. 每页单独切块，再合并进 SQLite FTS5 trigram 索引；块不会跨越 PDF 页面。搜索结果带真实 PDF 物理页码（1-based）及块序号/文档版本，点击结果由本地 SQLite 重新获取同一原文片段，而不是按字符偏移猜测证据。
5. PDF 复习卡在创建时保留用户选择的原文证据、来源文件哈希和物理页码；用户修改 PDF 后手动重新导入时，变更哈希触发全量原文重新索引和旧复习卡“需核对”标记，不能将原引用悄悄当作新事实。相同路径且二进制哈希未变不会重复导入。
6. 原始 PDF 不复制到 SQLite；本地数据库保存提取出来的**文字快照、PDF 源路径、SHA-256、真实页数和块到页码映射**。删除知识库记录会删除索引/引用卡，但不删除原始 PDF。手动数据库备份包含这些文字快照与引用元数据，**不含原 PDF 二进制**。
7. SQLite `ate-knowledge.sqlite` 从 v1 事务升级到 **v2**，新增 `knowledge_pdf_sources`、`knowledge_chunk_pages` 及复习卡 `source_page`。为了保护既有 v1 的 `format` CHECK 约束，PDF 在基础文档行内部按文本存储、通过元数据表向 API 明确标记 `format:"pdf"`。老 Markdown/TXT 和复习卡仍保留。Electron 在打开数据库前先用 WAL-aware 在线备份 API 创建并校验 v1 快照，备份失败则停止迁移。
8. 新增只读 `knowledge:passage` IPC：参数是文档 UUID 和合法的数字块序号，查询 Main 中已存的原文，不让 Renderer 请求任意文件路径或加载 PDF 中的活跃内容。所有显示都为 React 普通文本，不渲染可执行 PDF/HTML。

## 已知边界与安全提醒

- 页码是 PDF 文件的**物理页序号**，不一定等于页脚印刷的页号；这仍然是可查证的相对定位，但不是 PDF 书签/批注中的精确坐标。
- 公式、复杂多栏排版、表格、乱码字体、图像中的文字无法保证完整或正确顺序。用户必须按原 PDF 核对关键出处，不能直接把抽取结果当作学术证据的最终权威。
- 解析发生在 Electron 主进程。本轮没有把不可信 PDF 解析隔离到单独 OS 子进程，不能保证恶意构造文件绝对不会拖慢或阻塞进程；只能导入自己信任或有合法来源的 PDF。未来应考虑隔离进程和更严格的内存/CPU 限额。
- 不读取网站 PDF、不做 OCR/ASR、不提取图像/附件、不自动向 AI/网络发送全文，也不提供 PDF 原文件内建阅读器。用户仍用自己的 PDF 阅读器查看原始文件。
- 本轮仍未提供完整的备份恢复界面；SQLite 备份未额外加密，可能包含私人课程文字快照，**不得上传公开 GitHub**。
- 不自动把 PDF 文本提供给 PR #12/13 AI Provider，知识库 AI 问答的逐段授权与引用审阅属于后续独立工作。

- IPC allowlist 以及 Windows/macOS TypeScript、Vitest、Electron bundle。

用户后续在自己的设备上选择一份**非敏感的两页可选择文字 PDF**，分别搜索第 1 页和第 2 页的不同关键词，点击搜索结果确认页码并创建复习卡；然后修改本地 PDF 并重新导入，确认卡片需核对；可再选扫描件验证 OCR 提示。请勿上传用户私密课程材料、备份或 API Key 给本助手。

本轮仅更新 GitHub 仓库锁定的 PDF 解析依赖，依赖安装/测试在 GitHub CI 托管 runner 上进行。**没有远程操作或安装任何软件到用户设备、没有使用 RDC、没有自行合并 main。**
