# ALPHA-CLOSE-02：V0.1 八模块真实工作台与本机布局偏好

> 2026-11-25。接续已合并的 [ALPHA-CLOSE-01 邮件 AI + 多服务商](52_ALPHA_CLOSE_01_MAIL_AI_REVIEW.md)，属于 [51 五人内部 Alpha 收尾总计划](51_V01_FIVE_PERSON_ALPHA_CLOSEOUT.md) 的第二轮。此轮仅更换首页的模块聚合内容，保持 #48 独立视觉规划 PR 的设计文档及全局样式不变。

## 交付

1. 工作台提供八个独立的真实数据模块：**待办、已确认学习时间块/课程、专注、知识库/复习、小组、Canvas、邮箱、AI**。底部八卡覆盖日历、知识、专注、团队、AI、Canvas、邮箱的真实状态；首页自身的布局配置承担第八大模块“工作台”。
2. 待办来自已有本地 SQLite Task API，仅展示可见、未完成任务，按照最早截止日、同日优先级排序，忽略隐藏 Canvas 作业；今日截止、逾期与全部待办分开计数，可从首页完成任务或进入编辑页。不会把未确认学习时间块误标为已安排。
3. 已确认日程来自现有固定日历及学习规划 API；保留 Canvas 事件的 visible/missing 语义，过滤已隐藏和失效条目；按设备民用日期显示，不把 UTC 日期当作用户本地日期。专注分钟/完成场次/积分来自真实已保存的 FocusSummary，而非估算或静态常数。
4. 知识库摘要读取 Main 的本机 `knowledge.progress` 和 `knowledge.documents`，只显示统计，不展示文档内容。团队、Canvas、邮箱、AI 均分别调用**已经受 Main 权限控制的现有 IPC**；仅在团队已登录时通过受权限保护的工作空间接口读取当前有权访问的小组数量，不展示成员个人任务、邮件正文或密钥。
5. 连接器每项独立加载，拒绝或出错时显示“读取失败/未连接”，不会用演示数字替代；手动“刷新模块状态”，Canvas/邮箱同步完成时更新首页的状态。**状态已连接不等于真实服务已通过内部验收**，首页有显式说明。
6. 用户可打开布局设置，自行勾选每个模块的显示/隐藏、上移/下移排序，以及“均衡 / 学习优先 / 协作优先”三套预设。偏好独立存于当前设备 `localStorage` 的 `study-anchor.workbench.layout.v1`；不写入 SQLite、云端或外部服务。损坏、未知字段、重复模块、未来版本等一律回退默认。隐藏全部后仍有“显示全部模块”救援入口；存储不可用时不崩溃，并显示本次布局不会持久化的提示。
7. 独立 `src/renderer/src/workbench.css` 与 `Workbench.tsx`。对 `App.tsx` 仅进行首页入口替换和连接器状态刷新订阅，不修改 `styles.css`、#48 的蓝图或全局视觉层。全部按钮配有 aria-label，组件显隐、预设等状态可通过键盘控制。

## 文件与测试

- `workbench-layout.ts` / `workbench-layout.test.ts`：完整模块集合、预设、上下排序、显隐、持久化严格 Schema、错误恢复及“全隐藏仍可恢复”的纯单元测试。
- `workbench-data.ts` / `workbench-data.test.ts`：真实任务与已确认课程/计划的排序、逾期判断、隐藏/撤销同步过滤和纯函数无副作用验证。
- `Workbench.tsx` / `workbench.css`：各 IPC 来源独立读、拒绝错误状态、权限下的工作空间数量和模块跳转，布局界面与主题适配。
- `App.tsx`：保留日历、专注计时、AI、邮箱等页面现有状态和授权，仅将工作台主体接入新组件，并在后台 Canvas/邮箱已授权同步后刷新状态。

## 首版真实验收用例（Windows + macOS）

1. 使用独立 `STUDY_ANCHOR_USER_DATA_DIR`（或文档的兼容变量），建立 5 个普通任务：今日、逾期、未来、无日期、已完成；另创建隐藏 Canvas 任务，验证未完成/今日/逾期数量准确、首页按钮的完成/编辑生效，并在日历重启回读。
2. 保存一段已确认学习时间块、留一段仅建议的未确认块；首页只能统计确认过的时间。Canvas 已删除/已隐藏事件不能错误出现在日程预览；修改系统日期/时区后验证今日变化，不能混用 ISO UTC。
3. 知识库导入本机测试资料、创建复习卡、进行一次复习；首页到期数、资料数与知识库一致。关闭网络，验证本机数据仍正常，未连接的云端模块明确提示。
4. 分别连接/断开合法测试的 Supabase、Canvas、邮箱及用户自有 AI Provider Key；在首页刷新后应显示真实状态，不能泄漏 Token、邮箱正文、成员私人任务；没有真实账号时记录 `Blocked`，不伪造通过。
5. “协作优先”预设 → 隐藏邮件和 AI → 上移知识模块 → 完全退出重启 → 布局不丢失；修改用户偏好为非法 JSON / 未知模块，重启回默认；隐藏全部时从救援按钮恢复。
6. Windows/macOS 分别使用鼠标和键盘操作布局控件，切换明暗主题和缩小窗口；导航到专注时正在运行的计时不能意外暂停/清零；回到工作台显示真实统计。
7. 最终提交的 CI 必须双系统完成 TypeScript、所有 Vitest、Electron desktop bundle、Python worker 语法以及打包后的离线 Worker smoke。自动化绿色不替代 GUI、真实小组五账号、Canvas/邮件权限和安装包验收。
