# W5-9 本地知识库、原文检索与离线复习（首个真实垂直闭环）

**状态：待 PR / Windows-macOS CI；真实桌面文件选取及用户体验尚待本机验收。**

## 已实现的切片

1. 独立 `ate-knowledge.sqlite` 数据库，不触碰个人任务/Canvas/邮箱原有数据权威。使用 Node 24 内置 SQLite，不引入原生 npm 模块。
2. 仅在用户点击「选择并导入资料」之后，弹出 Electron 原生操作系统文件选择器。只有 UTF-8 `.md`、`.markdown`、`.txt`、单文件不超过 2 MiB、不是符号链接的普通文件可导入。Renderer **不能提供本地路径**要求 Main 任意读取。
3. 原文保持在用户原文件中，知识库同时保留**本机原文文本快照**、来源绝对路径、SHA-256、导入时间、修订版本。文件内容未变化则不重复导入；相同路径更改内容时事务性重建索引并增加修订号。
4. 按约 1100 Unicode 字符切分、100 字符重叠，建立 SQLite **FTS5 trigram** 检索索引。搜索命中返回真实文档、版本、片段序号与摘录。小于 3 字符的查询以已参数化的 SQLite 子串搜索补足中文短词。
5. 可从选中的文档原文片段**由用户手工编辑**问答复习卡，自动保存原片段快照与来源哈希。改变来源文档后卡片标记 `needsReview`，不把失效的旧证据悄悄当成新事实。
6. 复习中先显示问题、用户点击再看自己编写的答案和当时原文证据。用户手动评价「重新学、困难、掌握、容易」，程序根据确定性日间隔更新下次复习。一天最多记录一次评价，防重复操作。
7. 删除知识库资源时删除其索引和关联卡片，**不删除或修改硬盘原文件**。所有内容默认仅在此设备，既不会共享到 Supabase，也不向 AI 服务/邮箱发送。

## SQLite 版本、保存与恢复

- 新知识库单独从 schema v1 起步，`PRAGMA user_version = 1`，使用一个事务创建 FTS、文档、分片、复习表与触发器；未知未来版本拒绝降级。
- 保留目前的 `ate-local.sqlite` schema v4；**在启动时若发现 v4 之前的现有任务数据库，自动先做验证通过的在线备份，再运行旧库升级**。知识库未来升级也走同一迁移前备份入口。
- 手动「备份本地数据库」通过 Node SQLite 官方 `backup()` API 为个人任务、邮件元数据缓存和知识库分别建立可打开的单文件快照，并以 `PRAGMA quick_check` 验证；放到 Electron 自己的 `userData/backups/` 唯一目录，生成 manifest。
- SQLite WAL 不是备份，直接复制 `.sqlite` 可能漏掉 WAL 新数据；此处使用 SQLite 在线备份，而不是文件拷贝。
- **重要**：这些备份**未额外加密**，包含用户私人任务、收件箱发件人/主题和资料全文。仅在本机用户资料目录创建，请用系统磁盘加密/访问控制防止他人读取；**不包含**系统密文凭据文件、Supabase 账号会话、资料原文件或附件。
- **尚未实现可视化恢复/自动清理策略**。备份失败会阻止迁移，绝不覆盖旧数据库。恢复必须在独立备份副本和用户明确确认后另行开发/验收；不能把已有备份按钮描述成全套灾难恢复。

## 当前复习规则（不是 FSRS）

新卡片默认当天到期。第一次「重新学」+1 天、「困难」+2 天、「掌握」+4 天、「容易」+7 天；下一轮则按照旧间隔近似 1.5/2.2/3 倍增加，最长 365 天；日期基于 UTC 日历日。用户评分是唯一评分依据，不自动由 AI 给出掌握度，不生成正式日历事件。

## 自动化测试 / 人工验收

GitHub Windows/macOS CI 应完成 TypeScript、Vitest、Electron bundle。单元/集成测试覆盖 FTS5 英文/中文搜索、短词后备、真实片段、同路径 SHA 去重、重导入修改旧卡证据核验、删资源及 FTS 触发器、复习调度和一天幂等、UTF-8/2 MiB/符号链接安全、真实 SQLite 在线备份/quick_check、v3 → v4 迁移前快照。

本地验收时：
1. 点击「个人知识库」→「选择并导入资料」，选一份自己可公开或可安全测试的 UTF-8 Markdown/TXT；
2. 搜中文/英文词，点击结果，确认原文摘录与修订号；
3. 手工写问题/答案并保存复习卡，切「今日复习」评分，重启检查是否持久化；
4. 用原编辑器修改 TXT/Markdown，手动重新导入，观察旧卡提示证据待核验；
5. 点击「备份本地数据库」检查 manifest 与三个 `.sqlite` 文件存在，**不要分享给助手或上传 GitHub**。

本轮不使用 RDC，不操作你的电脑，不引入 npm 依赖，不合并 `main`。
