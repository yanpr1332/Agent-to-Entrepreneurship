**排序可调整**：实际开发中可平行实现独立模块，但最终版本只有在全部 P0 通过验收后才达到已经批准的产品定义。对依赖第三方审批的功能要提前做技术验证，不能在发布时把模拟数据当作真实接入。

### W2 给工程批次增加的不可遗漏交互要求

- **批次 A**：首启可本地使用/独立登录/可选 jAccount，统一的权限反馈与离线失败状态，八模块导航与个人/团队/AI 项目切换；非校园用户不能被挡在核心功能之外。
- **批次 B**：连接器显示每个平台授权范围、同步/撤销及失败状态；邮件按邮箱/文件夹允许 AI 分析，草稿与最终发送确认严格分离，未知发送结果不自动重试。
- **批次 C**：知识图谱区分 AI 待核验/已确认边，自动复习使用用户最终评价；可追溯问答引用；个人资料被团队共享前须明确挑选与授权。
- **批次 D**：AI 项目支持选择文件/文件夹、排除子目录、服务范围与有效期，且本地读取与云外传分开；AI 规划候选与正式时间块分离，只选择性应用。
- **批次 E**：专注轻量/严格双模式、始终安全退出与崩溃恢复；团队任务 P0 单负责人可选验收，按重要程度配置多审核人明确保留 P1 扩展点。
- **批次 F**：工作台组件显隐/排序/尺寸、布局预设、主题和本地背景；跨设备逐文件云同步、版本冲突解决、双 OS 托盘及键盘交互。

各要求的页面动作和验收反例见 [W2 逐项决策](ui-ux/02_INTERACTION_DECISIONS.md) 和 [W2 验收清单](ui-ux/05_W2_ACCEPTANCE.md)。

## 测试和发布验收

1. 所有 P0 功能都需对应具体测试用例和用户场景；不仅是组件能运行。
2. Canvas/学校教务/邮件、Google/Outlook 日历和 Notion 必须经过真实账号/真实数据验证，并记录授权和正式发布状态。
3. Windows/macOS 均通过核心操作、跨设备文件级选择性同步、离线和冲突恢复；不得使用仅 Windows 的成功结果代替 Mac 验收。
4. 自律限制须通过超时、崩溃、系统重启、手动紧急退出和权限撤销的安全测试；未通过不得开放高风险能力。
5. AI 资料访问按用户+项目+操作权限交集校验；邮箱发信必须逐次确认，未知状态不能盲目重发。
6. 用户与团队数据隔离、数据备份/导出、资源原件保护和用户权限撤销应有实际测试证据。

## 质量指标（待 W3/W4 量化）

- 课程及作业导入准确率、重复项比例、同步状态可解释性。
- 邮件事项抽取正确率、误创建率、重复发信事故数（目标为零）。
- 课程/资料导入流程完成率、问答来源准确性、复习计划实际可执行性。
- 规划采纳率、任务完成率、专注退出及恢复成功率。
- 账号注册、团队协作成功率、权限越权测试结果、云同步冲突恢复率。
- 双平台缺陷数量、核心 E2E 通过率、性能/启动/检索延迟。

**注意**：工期与性能阈值不在此阶段凭空确定；须在 W3 可行性验证后由 W4 提供可执行排期。当前没有已交付的软件版本。

## W4：V0.1 内部 Alpha 交付轨道（2026-11-07）

**目标日期：2026-11-25。** 该目标是五名学生团队的内部原型，不是正式产品发布或应用商店上架。Windows 与 macOS 均需可运行；五名成员通过互联网云端进入同一工作空间；八大模块均有可操作的基础闭环。

### Alpha 必交付门槛
- M1：本地任务/日历基本操作、持久化、ICS；Canvas 作业可映射为带来源的个人任务。
- M2：PDF/Markdown/TXT 导入与检索、知识图谱、跨文档关系和基础自动复习必须真实可操作。
- M3：专注计时、记录与积分。
- M4：五个独立账号、共享工作空间、团队任务和消息、服务端权限隔离。
- M5：真实 AI Provider、用户选定上下文、候选任务及确认写入。
- M6：Canvas 真实读取；开发者个人 Token 仅限本人本地验证，OAuth 多用户方案依赖 Developer Key；ICS 不可冒充 Canvas API。
- M7：交大邮箱优先，通用 IMAP/SMTP；真实收件、草稿、逐次确认发送及邮件转任务候选。
- M8：工作台聚合、基础组件和主题；邮件中心仍为独立模块。

Canvas 真实读取与交大邮箱真实收发是用户明确要求的 Alpha 必交付项。若认证/审批受阻，必须标记 Blocked，不得以模拟成功替代。Canvas Developer Key 申请是最高优先级并行外部任务。

### 正式 P0 不变
本 Alpha 选取限期原型闭环，不修改 PRD 的正式优先级。SJTU 教务 API、Google/Outlook Calendar、Notion 等其他正式 P0 仍保留在正式产品路线中；没有真实授权和验收证据时不能宣称已完成。完整正式 P0 需要后续迭代和完整发布门禁。
