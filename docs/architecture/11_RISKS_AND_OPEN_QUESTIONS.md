# W3 集中审阅风险与开放问题
> 集中审阅选择 B：保留 W3 架构并吸收 R01–R10 与身份/隐私/资源三项横向约束。设计已确认，不代表真实技术实测。

| 编号 | 风险等级 | 补强方案 | 正式发布前验证 |
|---|---|---|---|
| R01 | 高 | Electron 主/Preload/Renderer/Worker 隔离，常驻/必要后台和资源预算 | Win/Mac 安全 IPC 和长时间性能 |
| R02 | 关键 | SQLite 本地 Outbox、服务器权威、版本和增量游标 | 多设备离线、冲突、重放 |
| R03 | 高 | 模块公开 Port、唯一 Task、事件 Schema 与事务 Outbox | 契约和数据归属测试 |
| R04 | 关键 | Connector Engine、真实接入四阶段 | Canvas/jAccount/邮箱合法授权；Google/Graph/Notion OAuth |
| R05 | 关键 | 文件、AI、远端外传、云同步、团队共享五维独立授权 | 路径越界、撤权、索引/嵌入外传 |
| R06 | 高 | 按需解析/ASR、模型/硬件回退、可恢复计算 | CPU 低配设备、安装包大小 |
| R07 | 关键 | Win/Mac 分级专注、紧急退出和故障释放 | 真机强退、重启、撤权 |
| R08 | 关键 | 发信快照确认、MailSendAttempt、unknown 远端核验 | SMTP/API 超时不盲重发 |
| R09 | 高 | 逐文件原件、衍生数据权限、撤权和删除分离 | 跨系统文件、缓存、远端删除 |
| R10 | 高 | CI 安全、签名/公证、数据库迁移/回滚 | 正式安装/升级与恢复 |

## 横向约束
1. **身份**：匿名本地使用、独立云账户、可选校方账号和团队成员角色分开；跨设备授权不能继承本机目录权限。
2. **敏感信息**：Token、邮箱、录音、AI 会话、OCR、向量、摘要、团队资料和审计日志按分类最小化、权限过滤和加密保护。
3. **资源控制**：前台、完整后台、仅必要后台、完全退出分别定义允许运行的服务，度量内存/CPU/电量/网络。

## 未决事项与建议前置验证
| 问题 | 当前建议 | 阶段 |
|---|---|---|
| 云服务、区域、配额与费用 | Supabase 等成熟平台作为候选，适配接口与合同测试 | W4 预算/Spike |
| 云端 E2EE 范围 | TLS+静态加密是基线，团队搜索与 E2EE 取舍待讨论 | W4 安全 |
| SJTU Canvas/教务/邮箱授权 | 尽早申请合法开发与测试账号，真实 P0 门禁 | W4 首批 |
| Google/Outlook 日历、Notion | 验证公众 OAuth、租户管理员、限流 | W4 |
| 通用 IMAP/SMTP 支持范围 | 交大真实收发 P0；不自动承诺所有邮箱兼容 | W4 |
| macOS 最低版本/Intel/Apple Silicon | 实际设备及第三方依赖测试决定 | W4 |
| Windows ARM64 首版 | 尚未批准支持范围 | W4 |
| 增强专注实际限制力度 | 先双平台验证安全可逆措施 | W4 |
| 本地 OCR/ASR/模型 | 真实低配置设备测试，控制依赖体积 | W4 |
| Windows 签名、macOS 公证 | 正式发布必需的适用条件/证书/成本需落实 | W4 |
| 角色矩阵/文件容量/留存与删除 | 服务器强制 RBAC，数据生命周期分开 | W4 |
| 适用隐私法规、学校课件与录音版权 | 公开发布前审查 | W4 |
| W2 HTML 原型最终体验签收 | 尚未完成，不自动视为正式通过 | W4 前 |

**事实边界**：有接口文档≠合法获批；有模拟器≠真实 P0 验收；有 React UI≠Windows/macOS 原生限制成功；未签名测试包≠稳定正式版。P0 受阻须告知用户并取得决定，不能私自降为 P1。
