# W3 安全、权限和敏感信息模型
## 五维数据许可
| 维度 | 能做什么 | 不能自动获得 |
|---|---|---|
| 本地资源访问 | 指定文件/文件夹/排除子目录、读写及期限 | AI 项目读取 |
| AI Project 读取 | 仅本项目授权范围数据 | 向云模型外传 |
| AI 远端推理外传 | 向指定云模型/远端嵌入/云 ASR 传输指定片段 | 用户云同步 |
| 云同步 | 文件原件、仅元数据或 localOnly；按文件独立选 | 团队共享 |
| 团队共享 | 显式选文档/知识子集、指定成员与角色 | AI 任意访问 |

写入、删除、发信、邀请、改变团队任务、系统限制等高影响动作再经过独立 ActionGrant/确认。有效权限是用户权利 ∩ 工作空间角色 ∩ AI 项目范围 ∩ 当前动作许可 ∩ 实际处理位置许可；前端隐藏按钮不能代替执行层或服务端权限校验。

## Electron 安全
Renderer 开启 contextIsolation、关闭 nodeIntegration、使用适当沙箱；Preload 只暴露白名单 API，不直接提供全量 ipcRenderer、fs、exec。IPC 校验 Schema、消息来源、会话身份、权限、请求标识；主进程打开 URL 时校验协议/目的地；限制远端导航/新窗口、设置 CSP、默认拒绝无关系统授权。系统凭据保存在 OS 安全存储或受控服务端，避免原文写入日志、仓库和普通 SQLite 列。

## AI 和外部输入
邮件、PDF、网页、连接器返回值都属不可信数据，不能作为提升工具权限的指令。模型请求前对文件真实路径、符号链接、目录穿越、子目录排除及撤权做校验；云端嵌入也属于外传。OCR、文本切片、摘要、向量与图谱是可能含敏感信息的衍生内容，必须传播来源 ACL，撤权后清理/使索引失效并重检搜索可见性。

## 团队/同步安全
团队角色由云服务端最终判定；禁止只凭客户端 workspaceId 或 ID 检索私有资源。撤权立即拒绝新的服务器读取和写入；客户端回网后按策略停止访问和清理缓存；已离线保存到用户设备的副本无法保证被远程彻底删除。停止同步、清本地缓存、删除远端副本和删除本机原件分别处理。

## 审计与可靠性
最小审计字段 actor/workspace/resourceRef/action/purpose/destination/scope/requestId/time/result；不要记录 Token、全文邮件或课堂录音。账号/独立身份、可选 jAccount、设备、团队角色分别建模；换账号和注销须保住本地唯一原件。TLS、服务端静态加密、密钥管理属于安全基线；端到端加密范围与团队搜索的取舍仍待决，见 [风险](11_RISKS_AND_OPEN_QUESTIONS.md)。未经授权外传、越权共享、未经确认发信或失效的紧急退出都是 P0 发布阻塞项。
