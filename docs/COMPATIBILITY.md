# Windows / macOS 双平台兼容标准

## 硬性决策

Windows 是首要开发和调试平台，但 macOS 不能留到 Windows 完成后再移植。共享业务逻辑、数据结构和用户界面；所有 OS 专有功能必须走抽象接口并单独验证。

## 功能矩阵

| 能力 | Windows | macOS | 验收要求 |
| --- | --- | --- | --- |
| 任务、日历、知识库 | 必须 | 必须 | 相同核心功能、相同数据语义 |
| 离线编辑与本地存储 | 必须 | 必须 | 断网可读写、重新联网不丢数据 |
| 官方 API 同步 | 必须 | 必须 | OAuth/回调、超时、授权撤销稳定 |
| 邮件真实读取、AI 拟写与监督发送 | 首版必须 | 首版必须 | 相同邮件流程、权限提示、确认逻辑及发送状态 |
| 通知、托盘、开机行为 | 必须 | 必须 | 符合两平台权限和用户偏好 |
| Obsidian/文件导入 | 必须 | 必须 | 文件路径/权限/中文文件名无问题 |
| 语音处理、知识图谱、复习 | 首版必须 | 首版必须 | ASR/FFmpeg 依赖可部署，不强制 WSL；知识索引与复习逻辑一致 |
| 轻度专注 | 必须 | 必须 | 可随时退出，不影响重要系统能力 |
| 应用/网站限制 | 单独实现 | 单独实现 | 权限、安全退出、失败恢复实测 |
| 团队同步及聊天 | 首版必须 | 首版必须 | 双平台角色权限与冲突行为一致 |
| Google/Outlook 日历及 Notion 连接 | 首版必须 | 首版必须 | OAuth 回调、账号类型、同步状态和断开入口 |

| 逐文件云同步 | 首版必须 | 首版必须 | 同步选项、占位下载、冲突处理和原件保护 |
| 主题背景、组件、搜索和托盘 | 首版必须 | 首版必须 | 主题布局恢复、快捷操作及无障碍可读 |

## 发布与测试

- Windows：优先测试 Windows 11 x64；明确后续 Windows ARM64 支持计划。
- macOS：测试 Apple Silicon 和 Intel（如用户覆盖确有需要），明确定义最低支持系统版本。
- 持续集成：每次合并前构建和自动测试 `windows`、`macos`；原生权限相关功能增加真实设备测试。
- 安装包：Windows `.msi`/安装器；macOS `.app`/`.dmg`，正式分发前签名和公证。
- 多系统一致性：同一用户数据能导出/导入，避免硬编码路径、平台专用编码和 WSL 依赖。
- 个人文件夹权限不跨 OS 自动继承为另一个本机路径；用户须重新绑定。逐文件同步许可与云端 AI 外传许可独立。

## macOS 专注模式注意事项

Apple 的 App Sandbox 和文件权限会限制第三方应用的访问范围。不可假设可以使用 Windows 的进程控制机制或把 iOS 的 Family Controls 框架直接用于普通 macOS 应用。严格限制能力需要逐项做可行性验证，受限时必须明确降级，绝不承诺“无法绕过”。

## 当前未定

- macOS 最低支持版本和 Intel 支持期限。
- Windows ARM64 是否首发。
- 自律限制功能在各平台的最高可用能力及 OS 权限要求。
- 正式签名、公证与安装包发布渠道。

## W2 跨平台交互补充

W2 已确定统一混合工作空间布局、个人/团队/AI 项目切换和通用操作流程（详见 [页面架构](ui-ux/01_IA_AND_PAGES.md) 与 [交互状态](ui-ux/04_STATES_AND_PERMISSIONS.md)）。Windows 使用 `Ctrl+K`，macOS 使用 `⌘K`；通知区域与菜单栏分别适配原生习惯，缺权限时仍保留主应用操作入口。拖拽调整工作台组件需有键盘替代，浅色/深色主题、系统缩放和文本对比度不能因 OS 差异丢失。

用户在 Windows 为某 AI Project 授权 `D:\课程资料` **不等于** Mac 自动获得某路径的文件夹权限；跨设备只转移允许同步的元数据/原件，Mac 上使用前重新绑定对应本地目录。严格自律的可用操作、白名单、紧急退出及降级信息须分别按 OS 实际能力显示；HTML 原型不代替真机验收。
