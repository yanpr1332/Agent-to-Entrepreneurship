> 本表是任务唯一索引。正式产品优先级仍以 PRD 为准。“Alpha 门槛”表示 2026-11-25 内部原型交付要求，不等于把其他正式 P0 降为 P1。初始状态均为“待开始”；只有代码/配置、测试结果和验收证据齐全后才能标记“已通过”。

## 状态定义
- 待开始：尚未动工。
- 进行中：已有临时 Driver 并正在实施。
- 待验收：实现完成，等待独立复核。
- 已通过：符合验收标准且证据已归档。
- 阻塞：依赖、授权、设备或技术问题阻止继续。
- 不纳入本轮：仅用于明确不属于 11 月 25 日 Alpha 的工作；不得用于暗中降低正式 P0。

## 任务领取与冲突控制
- 本表不把任务永久分配给具体成员。团队按当周时间、能力和兴趣动态认领。
- 每项进入“进行中”的任务必须记录一名临时 Driver、一名 Reviewer、关联 Issue/PR、负责文件/目录、依赖和验收人；这不是永久岗位。
- 同一时间，同一高冲突文件/目录只允许一个 Driver 修改。需要并行时先拆分接口或文件边界。
- 公共合同、数据库 Schema、权限模型、连接器核心接口的改动必须先提交设计说明并经相关模块复核。
- 任何任务都不得直接修改另一模块的数据库表；通过模块 Port/事件契约协作。
- 具体执行状态、负责人和证据链接应在 GitHub Issue/PR 中维护；本文件只保留任务定义和唯一 ID。
